# 执行步骤

1. 案例建档：为每条候选路线建立企业样本卡，记录技术节点、组织协同与交付记录。
2. 成本分层：拆分研发投入、设备/材料约束、良率爬坡成本与供应链依赖成本。
3. 收益映射：把性能提升映射到具体场景收益，避免用抽象峰值代替真实价值。
4. 风险演练：模拟需求波动、规则变化和关键环节失效下的交付表现。
5. 触发复评：设定复评触发条件（良率异常、成本漂移、需求迁移）并定期更新判断。

## 关键规则

- 不用单一性能指标替代路线判断。
- 先验证可交付，再放大产能叙事。
- 任何结论都要写明证据等级与更新时间。

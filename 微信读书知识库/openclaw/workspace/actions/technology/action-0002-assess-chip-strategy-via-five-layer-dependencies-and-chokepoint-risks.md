# 执行步骤

1. 分层：将事件映射到设计、设备、制造、封测、市场规则五层。
2. 卡点：识别每层是否存在高集中度关键节点。
3. 约束：判断政策、许可和标准对节点访问的限制。
4. 替代：评估替代路径成本、时间与可行性。
5. 结论：输出短期冲击与中长期结构变化两类判断。

## 关键规则

- 先看系统层，再看公司层。
- 不把产能数字等同于自主能力。
- 每个结论都要标注时间尺度与不确定性。

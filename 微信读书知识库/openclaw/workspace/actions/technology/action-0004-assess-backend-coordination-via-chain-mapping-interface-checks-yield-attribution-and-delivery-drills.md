# 执行步骤

1. 链路拆解：把设计、前段、后段、测试、交付拆成可观察环节。
2. 接口体检：逐段检查输入输出标准、节拍匹配与异常处置机制。
3. 良率归因：将良率波动映射到具体接口与工艺变更，而非只看汇总指标。
4. 交付演练：用压力场景检验跨区域协同是否能在规则变化下维持交付。

## 关键规则

- 不把前段节点领先等同于全链路领先。
- 不把一次性爬坡当作长期稳定能力。
- 所有结论都写明证据等级与假设边界。

# 执行步骤

1. 时代断裂：定位故事所处历史转场与社会秩序变化。
2. 处境压力：识别人物在阶层、性别、职业与关系中的约束。
3. 时间侵蚀：观察青春、荣耀与身体如何被时间重写。
4. 记忆结构：区分地理故乡与记忆故乡的张力。
5. 叙事真实：检验文本如何通过可感经验建立真实感。

## 关键规则

- 先识别结构压力，再评价人物选择。
- 把情绪线索转译为机制线索。
- 用“可感真实”而非“事实对照”评价小说有效性。

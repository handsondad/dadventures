# 执行步骤

1. 冲击识别：确认变化属于突发尺度跃迁还是慢速侵蚀累积。
2. 模型更新：列出旧假设失效点，替换为可验证的新判断规则。
3. 叙事治理：重写自我与环境关系叙事，避免自我神化或自我否定。
4. 行动重建：把更新后的判断落到小步可执行任务并持续复盘。

## 关键规则

- 先更新解释框架，再放大执行力度。
- 同时修模型和修叙事，缺一都会反复失误。
- 以可验证小步替代一次性宏大逆转。

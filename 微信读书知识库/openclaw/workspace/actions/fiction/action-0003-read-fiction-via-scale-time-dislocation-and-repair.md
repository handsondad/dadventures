# 执行步骤

1. 尺度定位：判断冲击发生在文明层、制度层还是个体层。
2. 时间读取：识别变化是突发断裂还是缓慢侵蚀。
3. 位移诊断：标记角色在哪些坐标上失去原有稳定性（身份、家园、伦理、信任）。
4. 修复评估：观察文本如何提供谦卑、记忆重组与行动重建路径。

## 关键规则

- 先比较机制，不先比较文风。
- 把“情绪共鸣”转译成“判断规则”。
- 不同体裁可共用同一诊断轴。

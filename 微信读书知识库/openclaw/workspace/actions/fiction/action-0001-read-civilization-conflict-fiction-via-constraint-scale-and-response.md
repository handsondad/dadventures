# 执行步骤

1. 先标生存约束：核心冲突是否由资源/安全困境触发。
2. 再标技术尺度：关键技术是否改写了行动边界与成本结构。
3. 再看认知边界：角色是否因视角限制而系统误判。
4. 最后看制度回应：组织与文明如何重排规则应对新局面。
5. 归纳结论：提炼可迁移判断，不停留在剧情感受层。

## 关键规则

- 先看约束，再评人物。
- 技术变化优先当规则变化处理。
- 用制度回应检验叙事的现实迁移价值。

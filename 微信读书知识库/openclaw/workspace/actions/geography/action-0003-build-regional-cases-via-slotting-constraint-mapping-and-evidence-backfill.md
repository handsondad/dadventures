# 执行步骤

1. 建槽位：按北中南主带先建三个标准化案例槽位。
2. 画约束：为每个槽位标注地形与潜在水系约束方向。
3. 分证据：把条目分为已证事实、待证问题、工作假设三层。
4. 滚动回填：每次新增摘录只补对应槽位，不改动整体骨架。

## 关键规则

- 先结构化，再细节化。
- 假设必须显式标注，不能混写成事实。
- 每轮回填都保留可追溯来源。

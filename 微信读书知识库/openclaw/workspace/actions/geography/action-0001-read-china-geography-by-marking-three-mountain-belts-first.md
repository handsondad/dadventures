# 执行步骤

1. 在地图上先标三条主带：北带、中带、南带。
2. 确认每条带的代表山脉是否能连成线。
3. 后续每学一类新信息，先问它与哪一带关系更紧。
4. 定期回看骨架，避免学习重新碎片化。

## 关键规则

- 先骨架，后细节。
- 每次新增信息都要回到地图定位。

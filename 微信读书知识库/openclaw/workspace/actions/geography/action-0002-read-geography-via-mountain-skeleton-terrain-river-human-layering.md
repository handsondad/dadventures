# 执行步骤

1. 先标山脉骨架：北中南三条主带先在图上定位。
2. 做地形分层：按高低与连续性标出关键梯度区。
3. 提水系问题：沿骨架推测可能的水系约束方向并标记待证据点。
4. 叠人地关系：把聚落、通道与生产活动作为待解释层逐步挂接。
5. 记录边界：明确哪些是已证事实，哪些只是当前假设。

## 关键规则

- 不把假设当事实。
- 每轮新增信息都回填到同一底图。
- 提问质量优先于结论速度。

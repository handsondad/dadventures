# 执行步骤

1. 锚点核对：确认冲突条目是否引用同一地理锚点与同一来源层。
2. 等级回退：对证据不足的强结论先降级为待验证条目。
3. 并行记录：保留冲突双方表述，不做删除式“清洗”。
4. 待证提问：把冲突转成明确补证问题并绑定到对应卡片。
5. 复核升级：新增证据后再决定升级、维持或替换原判断。

## 关键规则

- 冲突先管状态，不先管面子。
- 先保证可追溯，再追求简洁叙事。
- 每次升级都要记录依据与时间戳。

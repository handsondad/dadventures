# 执行步骤

1. 锚点登记：把原始摘录中的确定事实先录入对应区域槽位。
2. 等级标注：为每条信息标注证据等级和不确定性标签。
3. 缺口提问：将未被证据覆盖的内容转成待验证问题。
4. 迭代更新：后续新增摘录只更新对应卡片与等级，不重写框架。

## 关键规则

- 先写已证锚点，再写待证问题。
- 假设必须带标签，不能伪装成事实。
- 每次更新都保留来源链路。

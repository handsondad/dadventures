# 执行步骤

1. 建矩阵：为每条主张填写来源类型、锚点、粒度、证据等级、冲突状态。
2. 挂冲突：把不一致条目成对登记，保留双方表述和对应来源。
3. 排优先级：按影响范围、可逆性、证据缺口给冲突分级。
4. 定窗口：为高优先级冲突设置最近复核窗口，低优先级进入待办队列。
5. 复核回写：补证后更新条目状态，并记录本轮变更依据与时间。

## 关键规则

- 没有字段化矩阵，不做“跨来源已验证”结论。
- 冲突不删档，只改状态。
- 先处理高风险高收益冲突，保持系统可持续推进。

# 执行步骤

1. 术语对齐：先统一关键词含义，特别是威胁、误解、协助、越界等高冲突词。
2. 共作试跑：先在低风险任务中验证对齐结果，观察承诺是否可执行。
3. 边界承诺：明确可做、不可做和需共同确认的行为边界。
4. 触发复核：约定何时启动防务动作，并在动作后做正当性复盘。

## 关键规则

- 恐惧不是直接触发攻击的理由。
- 先验证理解一致，再扩大协作强度。
- 防务动作必须满足必要性与可解释性。

# 执行步骤

1. 失效分型：区分情绪失控、语义错配、边界越位、解释权失衡等失效类型。
2. 成本分层：估算情绪降温、语义重对齐、边界复位、验证共作四类成本。
3. 低风险重启：先安排低风险、短周期、可回撤的协作任务。
4. 边界复位：重新声明职责边界、授权接口与触发条件。
5. 节奏复核：按固定节奏检查是否可扩容，否则回退到上一阶段。

## 关键规则

- 修复先算成本，再定强度。
- 重建先做小闭环，再做大协作。
- 每次升级都必须有边界与证据支撑。

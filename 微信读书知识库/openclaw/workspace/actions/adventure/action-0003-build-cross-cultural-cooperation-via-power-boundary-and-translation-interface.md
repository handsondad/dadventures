# 执行步骤

1. 权力盘点：写清双方资源、信息与决策权差异，先标记高风险失衡点。
2. 翻译对齐：统一关键术语和行动预期，约定出现误解时的澄清流程。
3. 协作试运行：从低风险任务开始，让规则先在小范围可执行。
4. 边界复盘：检查是否出现越权、误解积累或单边解释垄断，并及时修订规则。

## 关键规则

- 先限权，再授权。
- 先对齐词义，再对齐目标。
- 先小步试跑，再扩大协作范围。

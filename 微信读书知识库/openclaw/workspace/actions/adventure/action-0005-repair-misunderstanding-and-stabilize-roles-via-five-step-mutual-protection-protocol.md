# 执行步骤

1. 标注误读：先把冲突中的高风险句子和推断写出来，区分事实、解释和情绪。
2. 回放事实：仅用可验证信息复述事件顺序，暂停责任归因。
3. 对齐词义：逐个澄清威胁、冒犯、协助、授权等关键词的双方含义。
4. 重申边界：明确各自不能越过的职责边界与可请求支持范围。
5. 复核互保：约定在外部压力上升时，如何优先保护彼此最低行动空间与解释权接口。

## 关键规则

- 先修复误解，再讨论立场与责任。
- 任何越权代判都会侵蚀协作正当性。
- 互保协议必须可回看、可复核、可执行。

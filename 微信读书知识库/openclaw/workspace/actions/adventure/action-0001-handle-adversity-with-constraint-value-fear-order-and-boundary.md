# 执行步骤

1. 约束盘点：列出当前最硬约束，先看生存与连续性。
2. 价值重排：把资源按可用性和转化效率排序，去掉面子性需求。
3. 恐惧校准：把想象风险与可见风险分开，先降噪再判断。
4. 秩序重建：建立最小日常节律与生产循环，让系统可持续。
5. 边界校验：行动前检查正当性，区分防卫所需与越界惩罚。

## 关键规则

- 先稳系统，再追最优。
- 情绪失稳时不做不可逆决策。
- 正当性边界是长期秩序的一部分。

# 适用场景

这张动作卡适合那些已经发现几个问题总是一起出现的家长：孩子容易分心、回忆事情乱、遇到一点挫折就散掉，而家里又常常靠屏幕、催促和重复命令来顶着过日子。核心不是上一堆训练，而是把日常环境慢下来、结构清一点、对话更有叙事感，同时让孩子在可承受的规则和小挫折里慢慢长能力。

## 目标

- 减少注意力被屏幕和碎片刺激不断切碎。
- 帮孩子把一天中的经历组织得更有顺序和记忆点。
- 在不高压的前提下，慢慢提高挫折耐受和自我调节能力。

## 执行步骤

1. 尽量把电子产品和碎片化刺激降下来，尤其不要把它们当成专注力训练工具。
2. 每天保留一些慢而连续的活动，比如共读、拼搭、画画、运动、深呼吸或安静整理玩具，让孩子练习把注意力放久一点。
3. 孩子紧张或睡前难稳时，可以做简单的慢呼吸或身体放松练习，把专注和放松绑在一起练。
4. 吃饭后、睡前或放学后，花几分钟和孩子按顺序回顾今天发生的几件事，帮他补细节、找有趣点，也给消极经历留出口。
5. 讲故事和回顾时，尽量少碎问，多按顺序讲，帮孩子把人物、时间、发生了什么、感受是什么串起来。
6. 在日常里保留清晰一致的规则，比如作息、饭桌、屏幕时间和收拾流程，让孩子慢慢适应“不总能立刻如愿”。
7. 当孩子因为等待、被打断或规则而受挫时，先帮他稳定下来，不立刻全盘满足，也不冷硬推开，让他体验一点点可承受的不适并学会恢复。
8. 规则之外也给孩子留一点释放空间，比如运动、自由玩耍和喘口气的时间，避免结构过重把大脑压垮。

## 关键判断规则或话术

- 专注不是越快越好，而是越稳越好。
- 记忆不是只靠背，也靠把经历讲清楚。
- 自控不是马上不哭不闹，而是难受一下还能慢慢回来。

## 继续延展时的提醒

- 低屏幕不是万能药，关键还是要用真实活动和真实对话把空出来的位置填上。
- 挫折练习的重点是“可承受”，不是让孩子独自硬扛到崩。
- 如果孩子长期明显失控、睡眠很差或注意问题极端严重，仍要考虑更底层因素和专业支持。

## 不适用场景

- 如果存在明确发育障碍、严重睡眠问题或情绪危机，这张卡不能替代专业评估。
- 这张卡也不适合把孩子推入明显超过承受范围的高压训练。

## 观察信号

- 孩子是否更能把一件事做完，而不是频繁被刺激带走。
- 回顾一天时，他是否比以前更能说出顺序、细节和感受。
- 面对小等待、小失望或小规则时，他是否比以前更快恢复。

## 检索提示

- 注意力，记忆，自控力，低屏幕，讲故事，规则，重点是看能力怎样在慢节奏和清晰结构里一起长出来。

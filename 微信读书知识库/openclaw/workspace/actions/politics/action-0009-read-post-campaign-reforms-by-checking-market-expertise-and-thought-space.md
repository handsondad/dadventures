# 适用场景

这张动作卡适合在你读一套体制怎样从群众政治、自我毁伤或高度计划中转向改革时使用。它尤其适合那些容易被压成 `放松管制`、`领导人换思路`、`经济开始市场化` 这种过粗结论的材料。

## 目标

- 把改革读成 `市场重新估计 -> 专业能力回归 -> 知识与思想再接通` 的连续问题。
- 避免把改革只理解成政策松绑，而忽略系统恢复弹性的内部条件。

## 执行步骤

1. 先看市场角色：系统是不是先把市场、竞争、商品关系和价格信号从意识形态敌人改成可用工具，用 `note-0017` 和 `concept-0017` 做支撑。
2. 再看制度语言：它是不是开始接受 `计划和市场结合` 这类说法，说明协调机制从单一命令走向组合使用。
3. 接着看干部标准：干部选拔是不是重新强调专业知识和专业能力，而不再主要围绕运动资历和忠诚符号展开，用 `note-0018` 和 `concept-0018` 做支撑。
4. 再看知识循环：知识分子、学术团体、翻译输入和思想讨论是不是重新进入系统内部，成为现代化的一部分。
5. 最后看恢复程度：如果市场信号、专业干部和思想空间只是口头存在，没有进入治理和判断循环，就不要轻易说系统已经恢复了弹性。

## 关键判断规则或话术

- 不要先问是不是完全市场化，先问市场是不是先重新获得了合法性。
- 不要只看政策文件，先看干部标准是不是真的回到了专业能力。
- 不要把知识分子关系变化当文化花边，先问它有没有变成治理学习能力的一部分。
- 不要把改革只压成松绑，先看系统有没有重新学会接收信号、吸纳知识和修正自己。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读改革转向，要沿着 `市场 -> 专家 -> 思想空间` 这条线看。
- 最值得提醒的误区是：把改革只读成政策表面变化，而不看系统有没有恢复学习能力。

## 不适用场景

- 当材料只讨论局部经济技术调整，而没有干部和思想空间线索时，这张卡会偏重。
- 当材料只涉及短期战术变化、没有结构性恢复迹象时，不适合强套这套读法。

## 观察信号

- 如果你已经能说清市场有没有重新合法化、干部是不是重新按能力选、知识和思想有没有重新进入治理，说明进入了修复层。
- 如果你还只停在 `领导人想改革` 或 `政策放松了` 这种表面描述，说明还没有进入结构层。

## 检索提示

- 改革开放，干部专业化，思想解放，重点是把市场、专家和思想空间连成一条修复读法。

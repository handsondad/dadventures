# 适用场景

这张动作卡适合在你读一套高度集中体制为什么能迅速建立能力、为什么后来又要试着做制度修补、以及它最后会不会失去纠错能力时使用。它尤其适合那些容易只盯着 `集中效率高不高`，却忽略系统后续弹性和反馈结构的材料。

## 目标

- 把高度集中体制读成 `能力建立 -> 修补机制 -> 纠错能力` 的连续问题。
- 避免只用动员力或意识形态标签去判断一套体制的长期风险。

## 执行步骤

1. 先看体制基础：它最初靠什么把资源、权力和社会接口压向中心。
2. 再看修补信号：有没有出现市场补充、地方调整、相互监督或集体领导等安排，用 `note-0011` 和 `concept-0011` 做支撑。
3. 接着看边界问题：法制是否真正被当成秩序基础，还是仍被当成形式和麻烦。
4. 再看反馈结构：下级能不能说真话，不同意见能不能进来，最高权威是不是仍有约束，用 `note-0012` 和 `concept-0012` 做支撑。
5. 最后判断风险：如果修补口存在但法制太薄、批评被堵，就要把重点转到系统是不是正在失去纠错能力。

## 关键判断规则或话术

- 不要只问它当时能不能动员，先问它后来有没有给自己补纠偏口。
- 不要把修补等同改向，先看它是不是在原有结构里增加弹性和反馈。
- 不要把法制只当形式，先看它能不能约束最高权力和保护批评。
- 不要把最大风险理解成第一次犯错，先看系统还有没有能力把错改回来。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：高度集中体制，要沿着 `建立能力 -> 补修补口 -> 看能否纠错` 这条线读。
- 最值得提醒的误区是：只看一套体制最会动员的时候，而不看它后面有没有办法防止自己越跑越偏。

## 不适用场景

- 当材料只讨论某项孤立政策成败时，这张卡会显得过于结构化。
- 当材料没有修补机制、法制边界和反馈信息时，这种读法会受限。

## 观察信号

- 如果你已经能说清系统有没有补市场活口、地方调整和共同决策结构，也能判断法制与批评是否还有效，说明进入了结构层。
- 如果你还只停在某个领袖个人好坏或某个政策口号上，说明还没有进入纠错层。

# 适用场景

这张动作卡适合在你准备理解一条工业化路线为什么会转向重工业优先、一套计划体制为什么会变成社会控制结构、或者市场补充为什么总会重新出现时使用。它尤其适合那些容易停在 `计划还是市场`、`重工业还是轻工业` 这种口号对立的场景。

## 目标

- 把工业化和计划体制读成优先级、代价分配和资源控制问题。
- 避免只从意识形态标签去理解工业化路径。

## 执行步骤

1. 先看优先级：国家首先要保的是安全、独立、民生还是增长速度，用 `note-0007` 和 `concept-0007` 做支撑。
2. 再看代价分配：哪一部门、哪一群体承担了主要现实代价，统购统销、税收和价格制度各起什么作用。
3. 接着看资源入口：粮食、就业、教育、流动和产权这些关键接口，哪些被国家收进中枢，用 `note-0008` 和 `concept-0008` 做支撑。
4. 再看组织依附：个人和群体是否被固定进合作社、单位、区域和配给体系。
5. 最后看市场缝隙：系统在哪些局部不得不重新引入市场补充，以避免僵化和死滞。

## 关键判断规则或话术

- 不要先问路线对不对，先问国家想优先保什么。
- 不要只看产值目标，先看谁在为工业化付账。
- 不要把计划体制只看成表格和指标，先看它卡住了哪些资源入口。
- 不要把市场补充看成完全改向，先看它是不是为了修补系统僵化。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：工业化和计划体制，要沿着 `优先级 -> 代价 -> 控制 -> 补充` 这条线读。
- 最值得提醒的误区是：把意识形态口号当成全部解释，而忽略谁承担代价、资源怎么被锁进中枢。

## 不适用场景

- 当目标只讨论某项单一经济指标时，这张卡会显得过于结构化。
- 当材料没有涉及代价分配、资源控制和制度入口时，这种读法会受限。

## 观察信号

- 如果你已经能说清国家优先了什么、谁为此付账、资源怎样被卡住，说明进入了结构层。
- 如果你还只停在 `计划好还是市场好` 这种评价上，说明还没有进入机制层。

## 检索提示

- 工业化，统购统销，计划体制，市场补充，重点是把优先级、代价、控制和补充连成一条读法。

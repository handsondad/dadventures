# 适用场景

这张动作卡适合在你读一场革命为什么会反过来冲击自己建立起来的制度、为什么一个运动能突然找到大批愿意投入其中的行动者、以及为什么它最后更像破坏而不像建设时使用。它尤其适合那些容易只停在 `领导人夺权`、`群众失控` 这种单点解释的材料。

## 目标

- 把自我毁伤型革命读成 `反修恐惧 -> 行动者准备 -> 重建能力` 的连续问题。
- 避免把大规模群众政治只理解成宫廷斗争或抽象理想主义。

## 执行步骤

1. 先看恐惧对象：体制是不是已经把制度稳定、常规治理和组织定型理解成蜕化或修正主义风险，用 `note-0015` 和 `concept-0015` 做支撑。
2. 再看动员方式：领导层是不是绕开既有制度，转而直接发动群众去冲击自己已有的秩序。
3. 接着看行动者基础：群众是不是临时被煽动，还是早已通过革命教育、舆论和政治语言被提前塑造出来，用 `note-0016` 和 `concept-0016` 做支撑。
4. 再看建设能力：运动有没有稳定、具体、可替代的新制度蓝图，还是主要停留在对旧秩序的攻击上。
5. 最后看结果结构：如果它越来越像 `破而不立`，就要把重点放回恐惧、行动者和制度替代能力的失衡上。

## 关键判断规则或话术

- 不要先问是不是单纯夺权，先问稳定是不是已经被怀疑成背叛。
- 不要把群众只当临时工具，先问他们是不是早就被教育成了可被调用的人。
- 不要只看运动口号多崇高，先问它有没有立得起来的制度方案。
- 不要把结果只归咎于失控，先看它是不是从一开始就更会破而不会立。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读自我毁伤型革命，要沿着 `恐惧 -> 行动者 -> 重建力` 这条线看。
- 最值得提醒的误区是：把文革式运动只压成高层权斗，而不看系统为什么会主动重新打开革命。

## 不适用场景

- 当材料只讨论局部清洗或短促政争时，这张卡可能会显得过于结构化。
- 当材料没有行动者形成和制度替代能力的线索时，这种读法会受限。

## 观察信号

- 如果你已经能说清一场运动为什么害怕稳定、谁被提前训练成行动者、以及它为什么破多于立，说明进入了结构层。
- 如果你还只停在人物动机或情绪评价上，说明还没有进入自我毁伤机制层。

## 检索提示

- 文革，继续革命，反修防修，红卫兵，重点是把恐惧对象、行动者基础和重建能力连成一条读法。

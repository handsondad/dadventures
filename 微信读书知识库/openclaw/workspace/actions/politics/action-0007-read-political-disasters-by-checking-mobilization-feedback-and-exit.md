# 适用场景

这张动作卡适合在你读一场大规模政治灾难为什么会从激进目标滑向真实伤害、为什么一个强体制会把局部错误放大成全国灾情时使用。它尤其适合那些容易只停在 `领袖错了`、`政策太激进` 这种单点解释的材料。

## 目标

- 把政治灾难读成 `动员能力 -> 反馈结构 -> 求生出口` 的连续问题。
- 避免把灾难只理解成道德失败或单一政策失误。

## 执行步骤

1. 先看动员基础：资源是不是已经高度集中，社会是不是已经被广泛组织，领袖权威是不是足够把不确定目标迅速全国化，用 `note-0013` 和 `concept-0013` 做支撑。
2. 再看目标升级：原本是否应该局部试错的设想，被变成了必须统一执行的政治任务。
3. 接着看反馈链条：基层能不能反映真实痛感，坏消息能不能一路上行。
4. 再看求生出口：人能不能迁移、逃离、外流，局部灾情有没有泄压通道，用 `note-0014` 和 `concept-0014` 做支撑。
5. 最后看中心修正：上层收到的到底是真信号还是好消息，系统是在修正目标还是继续把错误关在里面。

## 关键判断规则或话术

- 不要先问目标是不是太左，先问它有没有被迅速全国化。
- 不要把灾难只看成某次决策错了，先看坏消息还能不能上去。
- 不要忽略人口流动，先看人还有没有离开最坏处境的出口。
- 不要把伤害规模只归因于第一步，先看系统有没有把错误关住并继续放大。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：政治灾难，要沿着 `动员 -> 反馈 -> 出口` 这条线读。
- 最值得提醒的误区是：把大规模灾难只归结为某个口号或某个人，而不看整个结构怎样让错误放大。

## 不适用场景

- 当材料只讨论单一干部决策或局部事件时，这张卡会显得过于宏观。
- 当材料没有反馈结构和人口流动信息时，这种读法会受限。

## 观察信号

- 如果你已经能说清一项实验怎样被全国化、坏消息怎样被阻断、人怎样失去出口，说明进入了结构层。
- 如果你还只停在口号、人物动机或抽象道德评价上，说明还没有进入灾难机制层。

## 检索提示

- 大跃进，饥荒，信息封锁，盲流，重点是把动员、反馈和出口连成一条读法。

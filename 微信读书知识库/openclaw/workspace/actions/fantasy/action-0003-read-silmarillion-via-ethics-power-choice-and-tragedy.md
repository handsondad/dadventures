# 执行步骤

1. 伦理母题：先定位堕落、必死、创造等长期主题。
2. 力量逻辑：识别角色如何从创造滑向控制。
3. 抉择路径：梳理关键节点上的判断与替代选项。
4. 悲剧机制：判断命运压力与误认如何共同触发后果。

## 关键规则

- 不被名词密度带偏，先抓机制线。
- 先问权力如何运作，再问谁输谁赢。
- 把悲剧当结构结果，不当偶然事件。

# 执行步骤

1. 约束机制：先识别神话约束如何跨角色与跨代运行。
2. 心理反应：再看角色在压力下的认知与情绪偏转。
3. 伦理细节：观察关键人物如何处理权力、羞辱与克制。
4. 世界补缀：最后定位这些片段补了哪条世界规则或历史链条。

## 关键规则

- 不以“是否完整讲完”判定文本价值。
- 把人物反应放回约束系统里解释。
- 先找机制增量，再看情节增量。

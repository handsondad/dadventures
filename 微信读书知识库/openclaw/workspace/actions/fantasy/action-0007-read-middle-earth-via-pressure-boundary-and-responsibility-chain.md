# 执行步骤

1. 压力识别：标记景观、诅咒、战争等长期约束如何塑造行动空间。
2. 边界判断：识别角色在力量诱惑前设定或放弃了哪些边界。
3. 误认排查：记录归因错位与认知误判如何放大悲剧。
4. 责任承接：追踪谁在限制条件下持续承担任务而不转向支配。
5. 历史转向：总结哪些小决策最终改变了大结构走向。

## 关键规则

- 先找机制链，再看角色魅力。
- 先问边界是否守住，再问胜负结果。
- 跨书比较时统一用同一诊断轴，避免碎片化解读。

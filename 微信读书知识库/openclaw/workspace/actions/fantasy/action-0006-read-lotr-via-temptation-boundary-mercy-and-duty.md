# 执行步骤

1. 诱惑识别：标记“为了行善而想掌控力量”的段落。
2. 边界设定：区分哪些力量是可协商使用，哪些必须拒绝占有。
3. 怜悯判断：记录文本如何反复延迟“终局裁决”。
4. 责任承接：追踪弱者如何在受限条件下完成关键行动。

## 关键规则

- 不把胜利简化成火力优势。
- 先问边界是否清楚，再问执行是否高效。
- 读到黑暗高压处，优先找“责任仍在”的证据。

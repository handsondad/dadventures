# 适用场景

这张动作卡适合在你读信贷周期、债务危机、去杠杆、货币危机或资本流动问题时使用。它尤其适合那些容易被讲成 `借太多了`、`市场恐慌了` 这种静态道德判断的材料。

## 目标

- 把债务危机读成 `信贷用途 -> 周期放大 -> 现金流断点 -> 币种约束 -> 去杠杆分摊` 的连续结构。
- 避免只盯着债务总量，而漏掉支付链条和政策空间。

## 执行步骤

1. 先看信贷用途：借来的钱是投向能产生未来收入的地方，还是只在提前透支需求和资产价格，用 `note-0013` 和 `concept-0013` 做支撑。
2. 再看周期结构：价格、收入、借贷和预期是不是已经开始互相强化，尤其要看是不是到了“越好越脆”的顶部。
3. 接着找现金流断点：真正出问题的是谁先付不出来、哪条支付或再融资链最先卡住，用 `note-0014` 和 `concept-0014` 做支撑。
4. 再看币种约束：债务是本币还是外币，决策者能不能印钱、延长期限或分摊损失。
5. 最后看去杠杆路径：这次出清更像温和摊平、强行收缩，还是通胀式减债，并判断谁会承担主要代价。

## 关键判断规则或话术

- 不要先问债有多少，先问债把未来拉前了多少。
- 不要先问大家是不是恐慌，先问现金流是在哪里断的。
- 不要把本币债和外币债混着看，它们的政策空间完全不同。
- 不要把去杠杆当自然现象，先看损失是如何被分摊和拖开的。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读债务危机，要沿着 `信贷用途 -> 现金流断点 -> 币种约束` 这条线看。
- 最值得提醒的误区是：把危机解释成“借太多”而不看支付链和政策空间。

## 不适用场景

- 当材料只讲企业个案，没有宏观信用和政策处理线索时，这张卡会偏重。
- 当材料只讨论短期市场波动，没有债务结构和现金流问题时，不适合强套这套读法。

## 观察信号

- 如果你已经能说清信贷如何前置需求、危机在哪里断、政策怎么接，说明进入了结构层。
- 如果你还只停在 `债务很高所以会出事`，说明还没有进入结构层。

## 检索提示

- 信贷周期，现金流危机，本币债，外币债，重点是把信贷用途、断点和政策约束连成一条线。

# 适用场景

这张动作卡适合在你读地位消费、品味竞争、时尚演变、阶层模仿或文化资本材料时使用。它尤其适合那些容易被压成 `有钱人爱买贵的`、`审美因人而异` 这种浅层结论的文本。

## 目标

- 把地位消费读成 `符号展示 -> 品味立法 -> 模仿扩散 -> 符号贬值` 的连续问题。
- 避免把品味政治只理解成个人偏好，而忽略它怎样帮社会维持差异。

## 执行步骤

1. 先看展示对象：哪些商品、空间、姿态和生活方式被用来证明成功或优越，用 `note-0005` 和 `concept-0005` 做支撑。
2. 再看判断标准：这些符号为什么会被视为高级，背后依赖的是财富、教育、举止还是文化资本。
3. 接着看立法者：是谁在先行定义新的高级感和区别方式，比如艺术家、时尚先锋或文化精英，用 `note-0006` 和 `concept-0006` 做支撑。
4. 再看扩散过程：这些符号是不是很快被模仿、复制和大众化，从而失去原本的区分力。
5. 最后看系统结果：如果差异一被复制就会贬值，就不要再把消费文化理解成稳定偏好，而要理解成持续翻新的差异机器。

## 关键判断规则或话术

- 不要先问谁买得更贵，先问谁在借商品讲一个更高位置的故事。
- 不要把品味看成纯私人审美，先看它是不是在划分可见的高低。
- 不要只看新品为什么流行，先看旧符号为什么会失效。
- 不要把潮流更新只归给商家，先看差异一旦被模仿就会怎样崩塌。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读地位消费，要沿着 `展示符号 -> 品味立法 -> 扩散贬值` 这条线看。
- 最值得提醒的误区是：把品味当成天然偏好，而不看它怎样服务于差异和阶层维护。

## 不适用场景

- 当材料只讨论价格波动或成本结构，而没有展示和差异线索时，这张卡会偏重。
- 当材料只涉及纯技术产品评价，没有地位和模仿问题时，不适合硬套这套读法。

## 观察信号

- 如果你已经能说清哪些物在公开讲述身份、谁在定义高级、旧符号又为何迅速过时，说明进入了结构层。
- 如果你还只停在 `有钱人更会买` 或 `年轻人总爱新潮`，说明还没有进入结构层。

## 检索提示

- 地位消费，品味政治，同与不同，重点是把展示符号、品味立法和扩散贬值连成一条线。

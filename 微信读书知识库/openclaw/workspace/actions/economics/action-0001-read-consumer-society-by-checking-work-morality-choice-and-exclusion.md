# 适用场景

这张动作卡适合在你读消费主义、现代贫穷、工作伦理或消费者社会材料时使用。它尤其适合那些容易被压成 `人越来越爱买东西`、`广告很厉害`、`消费观变了` 这种浅层结论的文本。

## 目标

- 把消费社会读成 `工作伦理 -> 消费资格 -> 排斥机制` 的连续问题。
- 避免把消费主义只理解成个人偏好，而忽略它怎样重写成员资格和贫穷定义。

## 执行步骤

1. 先看旧的成员模型：社会原来是不是先用工作伦理来塑造合格成员，把劳动、纪律和体面绑在一起，用 `note-0001` 和 `concept-0001` 做支撑。
2. 再看转折点：社会是不是从生产者逻辑转向消费者逻辑，把选择、体验和消费能力放到更高位置。
3. 接着看新的资格标准：谁能自由选择、持续消费、被承认为合格消费者，用 `note-0002` 和 `concept-0002` 做支撑。
4. 再看新的排斥对象：穷人是不是不再只是收入低，而是被定义成 `有缺陷的消费者`。
5. 最后看整合方式：这个社会到底主要靠伦理、纪律，还是靠美学、欲望和即时满足来让自己运转。

## 关键判断规则或话术

- 不要先问大家买了什么，先问社会想塑造什么样的人。
- 不要把消费只看成偏好，先看它是不是已经变成成员资格标准。
- 不要把贫穷只看成收入短缺，先看它是不是被文化化成消费失败。
- 不要只讲广告和品牌，先讲谁被允许自由选择、谁被排除在选择之外。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读消费社会，要沿着 `工作伦理 -> 消费资格 -> 排斥机制` 这条线看。
- 最值得提醒的误区是：把消费主义只讲成欲望膨胀，而不看它怎样重新定义体面和失败。

## 不适用场景

- 当材料只讨论具体产品营销技巧，而没有社会成员和排斥线索时，这张卡会偏重。
- 当材料只涉及短期消费波动、没有成员资格变化时，不适合强套这套读法。

## 观察信号

- 如果你已经能说清合格劳动者怎样被造出来、合格消费者怎样被定义、穷人怎样被排斥，说明进入了结构层。
- 如果你还只停在 `消费多了` 或 `人变浮躁了`，说明还没进入结构层。

## 检索提示

- 消费社会，工作伦理，有缺陷的消费者，重点是把劳动道德、消费资格和排斥机制连起来。

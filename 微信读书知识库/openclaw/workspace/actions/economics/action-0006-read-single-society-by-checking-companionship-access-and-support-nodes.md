# 适用场景

这张动作卡适合在你读独居、安全感、照料网络、关系基础设施或节点化社会材料时使用。它尤其适合那些容易被压成 `单身会不会孤单`、`多交朋友就好` 这种浅层结论的文本。

## 目标

- 把单身社会第二层读成 `可调用陪伴 -> 时间组织 -> 节点化支持` 的连续问题。
- 避免把独居只理解成房屋和婚姻状态，而忽略它怎样依赖外部节点运转。

## 执行步骤

1. 先看日常节奏：独居者在周末、空档和工作退场后，是不是会暴露出时间和情绪结构问题，用 `note-0011` 和 `concept-0011` 做支撑。
2. 再看陪伴接入：一个人是不是拥有足够多的朋友、活动、固定联系和主动寻求陪伴的能力。
3. 接着看家庭功能：原本由家庭承担的陪伴、照料和支持，被拆给了哪些节点，用 `note-0012` 和 `concept-0012` 做支撑。
4. 再看基础设施：这些节点是朋友、社区、服务、平台还是其他可调用人力，它们是否稳定可进入。
5. 最后看结果结构：如果独居安全感和单身社会稳定性都依赖节点接入，就不要再把问题只讲成结婚率或住房选择。

## 关键判断规则或话术

- 不要先问一个人住会不会孤单，先问他有没有足够的可调用节点。
- 不要把安全感只看成同住状态，先看它是不是一种接入能力。
- 不要把单身社会只讲成家庭变弱，先看哪些外部节点在接管家庭功能。
- 不要把支持理解成抽象温暖，先看它有没有具体的人、服务和时间结构。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读单身社会第二层，要沿着 `可调用陪伴 -> 时间结构 -> 节点化支持` 这条线看。
- 最值得提醒的误区是：把独居风险只归给单身本身，而不看支持接口是不是太少。

## 不适用场景

- 当材料只讨论婚恋文化争论、没有支持节点和生活运转线索时，这张卡会偏重。
- 当材料只关注人口统计、没有日常生活结构和基础设施变化时，不适合强套这套读法。

## 观察信号

- 如果你已经能说清独居者靠什么接住自己、社会又靠什么节点接住独居者，说明进入了结构层。
- 如果你还只停在 `一个人住更自由/更孤单`，说明还没有进入结构层。

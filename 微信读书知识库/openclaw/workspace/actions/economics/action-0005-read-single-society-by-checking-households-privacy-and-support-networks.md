# 适用场景

这张动作卡适合在你读单身、独居、婚姻去制度化、关系变化、照料网络或居住组织材料时使用。它尤其适合那些容易被压成 `年轻人不想结婚`、`现代人更自我` 这种浅层结论的文本。

## 目标

- 把单身社会读成 `生活单位变化 -> 隐私与独立可行化 -> 支持网络重组` 的连续问题。
- 避免把单身只理解成婚恋选择，而忽略它怎样重写居住、消费和安全感结构。

## 执行步骤

1. 先看生活单位：婚姻是不是已经不再垄断成年生活的组织方式，用 `note-0009` 和 `concept-0009` 做支撑。
2. 再看经济条件：隐私、独立和单人居住是不是已被收入、住房和市场服务做成可行选项。
3. 接着看市场偏好：单身和离婚后独立个体是不是被视为更可消费、更好承接的需求节点。
4. 再看支持问题：孤独是不是被错误地压成婚姻问题，而真正需要的是朋友、陪伴和社会网络，用 `note-0010` 和 `concept-0010` 做支撑。
5. 最后看未来结构：如果家庭单位不再默认兜底，就不要只问结婚率，而要问社会准备了什么替代性支持节点。

## 关键判断规则或话术

- 不要先问为什么大家不结婚，先问婚姻为什么不再是唯一可行容器。
- 不要把单身只看成价值观问题，先看隐私和独立是不是已经被市场做成可购买选项。
- 不要把孤独只归给未婚，先区分主观孤独和客观社会孤立。
- 不要只问家庭弱了什么，先问哪些网络和服务节点能接住原本由家庭承担的功能。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读单身社会，要沿着 `生活单位 -> 隐私独立 -> 支持网络` 这条线看。
- 最值得提醒的误区是：把单身社会讲成婚恋失败，而不看它怎样暴露居住和支持基础设施变化。

## 不适用场景

- 当材料只讨论婚恋心理或个体择偶技巧，而没有生活单位和支持结构线索时，这张卡会偏重。
- 当材料只涉及短期人口统计，没有关系网络和生活组织变化时，不适合强套这套读法。

## 观察信号

- 如果你已经能说清单人生活为何变得可行、市场为何偏爱它、以及支持为何要从家庭迁往网络，说明进入了结构层。
- 如果你还只停在 `现代人更自我`，说明还没有进入结构层。

## 检索提示

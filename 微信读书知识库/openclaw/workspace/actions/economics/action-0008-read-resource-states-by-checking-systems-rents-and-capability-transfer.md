# 适用场景

这张动作卡适合在你读石油国家、资源型经济、国有化、跨国公司与主权国家关系时使用。它尤其适合那些容易被讲成 `地下有油所以国家变强`、`把公司收回来就算拿回主权` 这种扁平结论的材料。

## 目标

- 把资源国家读成 `资源组织系统 -> 租金分配规则 -> 控制权变化 -> 能力转移` 的连续结构。
- 避免把资源问题只看成自然禀赋或单次政治动作，而忽略系统和 know-how。

## 执行步骤

1. 先看系统起点：资源开采是不是依赖外部资本、技术、设备和基础设施，用 `note-0015` 和 `concept-0015` 做支撑。
2. 再看组织关系：国家和公司更像对抗、代理，还是长期共生并共同长出一套能力系统。
3. 接着看租金规则：价格、牌价、税费和分账方式怎么定，用 `note-0016` 和 `concept-0016` 做支撑。
4. 再看能力转移：股权变化以后，运营、工程、管理和专业知识有没有真正进入国家体系。
5. 最后看真实控制：如果国家只是名义持有但不会组织和运营，那就不要把这叫作完全控制。

## 关键判断规则或话术

- 不要先问谁拥有资源，先问谁能把资源组织成收入。
- 不要把控制权只看成法律权属，先看定价、分账和运营是不是也变了。
- 不要把国有化只看成政治动作，先看技术和管理能力有没有一起转移。
- 不要把资源财富理解成地质事实，先看它是不是已经变成组织能力。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读资源国家，要沿着 `组织系统 -> 租金规则 -> 能力转移` 这条线看。
- 最值得提醒的误区是：把“国家拥有资源”直接等同于“国家已经掌握资源系统”。

## 不适用场景

- 当材料只讨论短期油价波动，没有国家、公司和能力结构时，这张卡会偏重。
- 当材料只讲纯技术采油工艺、没有制度和控制权变化线索时，不适合强套这套读法。

## 观察信号

- 如果你已经能说清资源如何被组织、规则如何重写、能力如何转移，说明进入了结构层。
- 如果你还只停在 `有油/没油`、`国有/私有` 二分法，说明还没有进入结构层。

## 检索提示

- 资源国家，石油公司，租金规则，能力转移，重点是把系统建设和控制权变化连成一条线。

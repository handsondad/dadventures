# 适用场景

这张动作卡适合在你读通胀性萧条、货币危机、国际收支危机、资本外流和外币债问题时使用。它尤其适合那些容易被压成 `多印钱会通胀`、`汇率跌了` 这种表层判断的材料。

## 目标

- 把债务危机第二层读成 `名义财富信任 -> 购买力冲突 -> 外部融资约束 -> 政策两难` 的连续结构。
- 避免只停在现金流断点，而漏掉货币信任和外部世界是否愿意继续融资。

## 执行步骤

1. 先看名义财富：货币和债务还是否被当作稳定的财富储存工具，用 `note-0019` 和 `concept-0019` 做支撑。
2. 再看购买力冲突：印钞和宽松是在缓冲崩塌，还是正在把痛苦改写成通胀和货币贬值。
3. 接着看外部融资：系统是不是依赖外部资本、储备和外币债，用 `note-0020` 和 `concept-0020` 做支撑。
4. 再看政策目标：决策者此刻更像在保汇率、保金融稳定，还是在保增长和就业。
5. 最后看真实约束：如果本币信任和外部融资都开始松动，就不要再把问题理解成普通去杠杆。

## 关键判断规则或话术

- 不要只问债能不能还，先问这些名义凭证还像不像财富。
- 不要只问印钞能不能救市，先问购买力损失会转给谁。
- 不要把国际收支危机只看成汇率问题，先看外部世界还愿不愿意继续融资。
- 不要把政策选择说得太轻巧，先看它是在选择谁承担哪种损失。

## 继续表达时的提醒

- 最适合作为判断句的一句话是：读债务危机第二层，要沿着 `名义信任 -> 购买力 -> 外部融资` 这条线看。
- 最值得提醒的误区是：把货币危机和外部危机都压成“市场恐慌”。

## 不适用场景

- 当材料只谈企业违约、没有货币和外部融资线索时，这张卡会偏重。
- 当材料只讨论短期汇率波动、没有政策空间和名义财富线索时，不适合强套这套读法。

## 观察信号

- 如果你已经能说清货币为什么会失去财富感、外部融资又为什么会突然变贵，说明进入了结构层。
- 如果你还只停在 `债太多/汇率跌了`，说明还没有进入结构层。

## 检索提示

- 货币危机，国际收支危机，外币债，重点是把购买力冲突和外部融资约束连成一条线。

# 执行步骤

1. 价值边界：是否明确哪些手段不能用、哪些底线不能破。
2. 训练纪律：是否存在可复盘、可重复的能力提升机制。
3. 协作机制：是否把个人能力嵌入团队决策与角色互补。
4. 制度承接：是否有组织流程保证成果可持续与可传承。

## 关键规则

- 不把短期高光等同长期卓越。
- 同时评估能力上限与品格边界。
- 任何成长方案都要回答“谁来承接、如何延续”。

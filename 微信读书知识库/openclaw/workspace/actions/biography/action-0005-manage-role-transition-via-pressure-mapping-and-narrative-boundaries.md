# 执行步骤

1. 压力映射：列出角色升级后新增的责任、可见性与后果放大点。
2. 承接设计：为高频高压场景配置节奏、分工与复盘机制。
3. 叙事节制：区分对外表达与内部判断，避免口号替代证据。
4. 边界复盘：定期检查是否出现越权、失真或声望驱动决策。

## 关键规则

- 先设计承接机制，再追求高光输出。
- 先守方法边界，再扩大叙事影响。
- 先修稳定性，再谈不可替代性。

# 执行步骤

1. 前提检查：是否先有结论，再找材料配合。
2. 证据检查：核心论断能否被明确材料支撑与复核。
3. 组织检查：是否形成可持续分工与资料积累机制。
4. 传承检查：成果是否可被后续研究者继续使用和修正。

## 关键规则

- 先问问题来自哪里，再问答案是否漂亮。
- 口号不能替代方法。
- 让项目留下可继承的材料与路径，而非只留下立场。

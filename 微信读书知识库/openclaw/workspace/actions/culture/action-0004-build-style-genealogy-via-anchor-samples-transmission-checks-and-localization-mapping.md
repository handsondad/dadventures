# 执行步骤

1. 锚点建表：先列出有明确断代或编号的样本，记录形制、技法与功能信息。
2. 传播校验：为每类特征寻找跨区域传播线索，区分直接传递与独立出现。
3. 约束标注：标注材料、地理、机构与仪式用途等本地约束条件。
4. 吸收判定：判断是原样延续、局部改写还是系统重组，并写明证据等级。

## 关键规则

- 先样本，后结论。
- 先传播链，再谈影响强弱。
- 先标注证据等级，再输出叙述性判断。

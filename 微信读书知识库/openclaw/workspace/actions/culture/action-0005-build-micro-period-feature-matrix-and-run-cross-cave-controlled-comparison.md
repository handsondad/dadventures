# 执行步骤

1. 字段建模：先定义最小字段（年代锚点、窟形、功能、工艺、材料、传播线索）。
2. 样本入表：把已知锚点样本逐条入表，缺失项显式留空。
3. 洞窟对照：在同功能或相邻功能条件下做横向比较，避免乱比。
4. 约束标注：为每条判断补材料约束与网络位置说明。
5. 分级输出：按证据等级输出“可定论/待验证/仅假设”三类结论。

## 关键规则

- 没有控制条件的相似性判断一律降级处理。
- 字段先稳定，再扩样本，不反向倒推结论。
- 每轮新增摘录后优先更新矩阵，再改写叙述。

# 执行步骤

1. 冲突登记：把冲突特征、来源位置、影响字段逐项登记。
2. 维度评分：按影响范围、证据强度、可验证性三维打分。
3. 优先排序：先处理高影响高可验证冲突，低优先级进入观察清单。
4. 快速验证：针对高优先冲突补最小必要证据，避免过度扩展。
5. 结论回写：更新矩阵字段、结论级别和改写说明，保留版本链路。

## 关键规则

- 先排序后裁决，先证据后叙事。
- 不删除冲突痕迹，保留可追溯版本。
- 每轮回写都要标注“为何改写”。

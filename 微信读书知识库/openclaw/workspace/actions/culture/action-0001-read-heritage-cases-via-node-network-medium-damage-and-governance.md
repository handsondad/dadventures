# 执行步骤

1. 节点：先识别区位与门户功能，定位其在大区域中的角色。
2. 网络：再看贸易、宗教、文本与人员流动的连接结构。
3. 载体：识别文化沉淀的物质与组织载体，如石窟、经卷、译经体系。
4. 损伤机制：梳理破坏来源，区分外部冲击与内部管理失误。
5. 治理承接：评估专业能力、规则连续性与修护边界是否成立。

## 关键规则

- 先看系统条件，再谈个体行为。
- 保护成败主要由治理连续性决定。
- 审美价值与治理价值要并行阅读。

# 执行步骤

1. 母题定位：先识别核心叙事母题及其在文本传统中的对应关系。
2. 风格分层：区分形制、构图、技法等层次，避免把差异混成单一风格标签。
3. 传播校验：检查母题和技法的流通链条，确认是本地突变还是网络扩散。
4. 再阐释边界：明确哪些解释有证据支撑，哪些只是启发性假设。

## 关键规则

- 先证据，后想象。
- 先分层，再比较。
- 先标注边界，再输出结论。

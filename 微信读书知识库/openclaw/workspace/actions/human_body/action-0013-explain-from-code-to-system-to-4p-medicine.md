# 适用场景

这张动作卡适合你准备整理基因组、系统生物学、精准医疗或未来医学主题时使用。它的目标不是把第六章拆成互不相干的三个名词，而是讲清一条递进线：先发现零件表不够，再发现真正重要的是调控网络，最后看到医学会因此从事后修理转向预测式管理。

## 目标

- 避免把基因组、系统生物学和 4P 医学讲成三个孤立术语。
- 把“为什么序列不够”讲清楚，再把“为什么需要系统视角”自然推出。
- 让未来医学听起来像模型变化，而不是科技宣传。

## 执行步骤

1. 先用一句总判断开场：拿到基因组序列，并不等于已经读懂身体。
2. 接着用参考序列、非编码区和开关编码讲第一层：基因组更像调控开关板，而不是纯零件目录。
3. 再用动态、网络和反馈回路讲第二层：当零件表不够时，问题自然会推向系统生物学。
4. 然后用 4P 医学讲第三层：一旦能持续读系统状态，医疗就会从事后修坏零件转向预测、预防和个体化管理。
5. 最后收束成一句话：现代医学越来越不像修理工，而越来越像读运行系统并提前纠偏。

## 关键判断规则或话术

- 不要把测序讲成终点，要讲成坐标系建立。
- 不要把非编码区讲成猎奇细节，要讲成“调控层进入视野”的标志。
- 不要把系统生物学讲成更大的数据库，要讲成研究互动和反馈的范式变化。
- 不要把 4P 医学讲成口号，要强调它背后是医疗目标从修理转向预测与管理。

## 继续延展时的提醒

- 最适合作为开头的一句话是：身体最难读的地方，不只是有哪些零件，而是这些零件怎样被调度。
- 最适合作为结尾的一句话是：当医学开始读系统状态，它就会越来越早地介入，而不只在坏掉之后补救。

## 不适用场景

- 如果目标是深入讲人类基因组计划史，这张卡会太框架化。
- 如果目标是细说精准医疗的现实局限和商业化问题，这张卡也不够展开。

## 观察信号

- 如果读者能把非编码区、系统生物学和 4P 医学复述成一条递进线，说明讲法有效。
- 如果读者开始区分“序列信息”和“状态信息”，说明主线已经立住。

# 执行步骤

1. 采集：每天记录素材，不评判先累积。
2. 初稿：开会前必须产出可讨论文本。
3. 试讲：用小范围真实反馈验证节奏与可理解性。
4. 复盘：按事实反馈拆分问题，不做人身归因。
5. 重写：保留核心风格，按反馈调整结构与节奏。

## 关键规则

- 意见是输入，不是命令。
- 问事实、问行为，少问抽象理由。
- 每轮改稿都要保留一处明确增量。

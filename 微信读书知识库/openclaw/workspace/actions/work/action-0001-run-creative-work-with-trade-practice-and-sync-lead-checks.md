# 执行步骤

1. 交易纪律检查：明确本轮产出、时间边界与交付标准。
2. 实践闭环检查：确保每次学习都配有可执行试验与复盘记录。
3. 同步引领检查：审视内容是否先建立共鸣，再完成有效推进。
4. 协作卫生检查：会议前有初稿，沟通多问事实少问动机，保护长期信任。

## 关键规则

- 不能落地的学习不计入成长。
- 不把情绪化反馈当成流程。
- 先守职业信誉，再追短期快意。

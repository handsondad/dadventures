# 适用场景

当你连续几天处于焦虑、拖延、抱怨、边界混乱或被动应付状态时，可用这张卡先恢复“可执行秩序”，而不是先追求情绪彻底好转。

## 目标

- 把注意力从外部失控项拉回内部可控项。
- 通过小而稳定的动作，重建责任感与行动感。

## 执行步骤

1. 姿态校准：先做 2 分钟身体校准（站直、呼吸、抬头、放松肩颈），把自己从塌陷姿态拉回执行姿态。
2. 节律锚点：当天固定三件基础秩序动作（起床时间、进食时间、睡前收口时间）。
3. 边界一句话：选一件正被侵蚀的边界，写并说出一句清晰表达，不解释过度，不情绪升级。
4. 最小责任动作：挑一项你一直回避的责任，拆成 15 分钟可完成单元并立即开始。
5. 晚间复盘：记录今天的“上行证据”1 条和“下行触发”1 条，明天优先复制上行动作。

## 关键判断规则或话术

- 先恢复可行动，再追求完美状态。
- 我不是要一次解决全部问题，我只做今天可承担的一步。
- 凡是让我更被动、更抱怨、更失序的动作，都应降权。

## 继续表达时的提醒

- 这套流程重在可重复，不在强度。
- 关键是每天不断线，不是一天做很多。

## 不适用场景

- 紧急安全风险或医疗问题，需要先走专业求助流程。
- 重大决策窗口期，这张卡更适合作为稳定底盘，而非替代专业判断。

## 观察信号

- 抱怨和空转时间减少，行动起步速度变快。
- 你开始更频繁地说“我今天能做什么”，而不是“为什么总是我”。

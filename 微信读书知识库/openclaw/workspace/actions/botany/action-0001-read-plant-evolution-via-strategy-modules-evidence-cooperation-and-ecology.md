# 执行步骤

1. 策略：先识别该类生命的核心生存策略与资源逻辑。
2. 模块：定位关键功能模块及其来源，如光合模块。
3. 证据：分离观点、假说和判决性证据的层级。
4. 协作：梳理共生互补如何解决环境约束。
5. 结果：归纳对生态格局和后续生命演化的系统影响。

## 关键规则

- 先看机制再谈结论。
- 用证据等级管理认知确定性。
- 用协作网络视角替代单体英雄叙事。

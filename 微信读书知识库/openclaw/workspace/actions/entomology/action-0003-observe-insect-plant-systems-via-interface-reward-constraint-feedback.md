# 执行步骤

1. 接口定位：识别昆虫与植物之间发生交换的具体接口。
2. 奖励识别：判断双方各自获得的收益类型与时序。
3. 约束识别：找出防御、筛选和成本机制。
4. 反馈判断：观察该互作如何影响局部与整体稳态。

## 关键规则

- 先看交换关系，再看单个物种标签。
- 每条互作都要写出“收益-成本-反馈”三联句。
- 观察结论要能回到系统层面的稳态解释。

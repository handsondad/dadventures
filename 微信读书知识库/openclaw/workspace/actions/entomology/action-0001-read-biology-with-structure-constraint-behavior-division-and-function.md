# 执行步骤

1. 结构识别：先抓共同体征与关键器官。
2. 约束定位：找出决定上限和边界的机制。
3. 行为解释：把观察到的行为与结构对应起来。
4. 分工分析：看个体与群体如何协作完成任务。
5. 功能归纳：总结其在生态系统中的关键作用。

## 关键规则

- 先机制后现象，避免只记结论。
- 每个现象都追问对应结构约束。
- 系统功能要放在网络关系里看。

# 执行步骤

1. 形态记录：先记腿数、体段、触角、翅与口器特征。
2. 行为观察：记录移动、取食、互动与防御方式。
3. 场景定位：标出其出现环境与时间窗口。
4. 归类判断：基于关键特征做初步分类并排除误判对象。
5. 系统评估：判断其在授粉、分解、控制或食物网中的角色。

## 关键规则

- 先观察再命名，不先入为主。
- 先看结构再猜行为。
- 每次观察都补一句“它对系统有什么作用”。

# 执行步骤

1. 暴露：确认接触路径与剂量可能性。
2. 复制：判断可能的宿主靶细胞与复制强度。
3. 反应：区分免疫保护与免疫过强反应。
4. 损伤：定位损伤来自复制还是炎症放大。
5. 边界：确定当前最优防控与沟通边界。

## 关键规则

- 不用单指标做结论。
- 先分层再归因。
- 决策同时写清收益与副作用。

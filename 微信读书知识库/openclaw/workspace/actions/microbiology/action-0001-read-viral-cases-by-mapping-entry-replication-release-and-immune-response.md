# 执行步骤

1. 进入：识别病毒依赖的受体与宿主细胞范围。
2. 复制：梳理它如何利用宿主完成转录翻译与组装。
3. 释放：区分裂解或出芽路径及其对细胞存活的影响。
4. 免疫：判断症状中哪些主要来自免疫反应而非直接损伤。
5. 结论：分别给出传播风险、组织损伤与症状机制三项判断。

## 关键规则

- 先画机制链，再下严重性结论。
- 把“病毒行为”与“宿主反应”分开描述。
- 避免只凭单个症状推断全病程。

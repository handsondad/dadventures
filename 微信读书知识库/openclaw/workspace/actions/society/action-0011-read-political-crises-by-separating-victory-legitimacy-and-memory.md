# 适用场景

这张动作卡适合处理高压政治事件、制度断裂叙事、革命与反革命争夺等材料。它尤其适合那些容易把“谁赢了”直接当成“谁更正当”的讨论。

## 目标

- 把危机阅读从胜负叙事拉回结构判断。
- 明确哪些行动在为长期制度复建保留接口。

## 执行步骤

1. 先看即时胜负：谁在当下掌握了组织与强制能力。
2. 再看程序正当性：是否保留可公开检验的规则、边界和责任链。
3. 再看长期记忆：哪些语言、见证与立场会被后续共同体继续调用。
4. 最后做综合判断：短期结果是否正在透支长期合法性，或是否仍保留复建空间。

## 关键判断规则或话术

- 胜负说明了力量分布，不等于说明了规范归属。
- 程序失效时，更要追踪谁在维护可复述的公共语法。
- 历史评价往往滞后于战场评价。

## 继续延展时的提醒

- 最适合固定的一句话是：政治危机不能只看谁赢，还要看谁为未来保留了可回归规则的接口。
- 最值得防范的误区是：把即时秩序误当成长期合法性。

## 不适用场景

- 对纯行政流程改进或低冲突技术问题，这张卡会过度政治化。

## 观察信号

- 如果你能把同一事件拆成三张不同结论，说明分析开始有层次。
- 如果讨论仍只有站队和情绪，说明还没进入结构层。

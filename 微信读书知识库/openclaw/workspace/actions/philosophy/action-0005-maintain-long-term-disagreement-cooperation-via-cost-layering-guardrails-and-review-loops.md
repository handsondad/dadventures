# 执行步骤

1. 分歧建档：把稳定分歧点、暂时共识点和争议术语分开登记。
2. 成本分层：标注理解成本、信任损耗、协调负担、复盘开销四类成本。
3. 护栏设定：约定反宣传底线（证据来源、论证密度、情绪动员限制）。
4. 周期复核：按固定周期回看分歧状态与成本变化，避免无效循环。
5. 规则回写：将有效做法写回协作协议，淘汰高成本低收益环节。

## 关键规则

- 分歧不必归零，但成本必须可控。
- 护栏先于热情，流程先于立场。
- 每轮复核都要产出可执行的规则改动。

# 执行步骤

1. 去口号：删除空泛立场句，把结论改成可讨论命题。
2. 补论证：为每个核心命题补上证据与推理链。
3. 标边界：说明适用范围、不确定性与反例条件。
4. 反例检验：主动列出最强反对意见并回答其关键挑战。

## 关键规则

- 没有证据链的断言不算论证。
- 先给可检验命题，再给价值立场。
- 每个结论都要附带边界说明。

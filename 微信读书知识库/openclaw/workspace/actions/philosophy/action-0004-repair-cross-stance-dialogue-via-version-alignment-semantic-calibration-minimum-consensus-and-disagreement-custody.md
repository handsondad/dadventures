# 执行步骤

1. 版本对齐：确认双方在讨论同一问题版本，而非不同命题。
2. 语义校准：澄清关键术语，标注各自定义与适用边界。
3. 共识收敛：提炼共享可检验命题，写明共同证据标准与下一步动作。
4. 分歧托管：将未收敛部分登记为可追踪分歧，约定后续验证路径。

## 关键规则

- 先修误解，再打分歧。
- 先收敛可检验部分，再保留价值分歧。
- 每轮讨论都要产出可执行下一步。

# 执行步骤

1. 校准：先用常识与经验代价检查主张是否脱离现实。
2. 分层：把内容拆为事实层、解释层、价值层。
3. 检验：仅对可检验部分给出证据要求与反例标准。
4. 比较：将竞争解释按解释力与继承性并列评估。
5. 沟通：明确确定性区间与不确定性来源，避免宣传化表达。

## 关键规则

- 不同层级不混为同一结论。
- 先问证据再问立场。
- 结论必须附带边界条件。

# 适用场景

适合读科学哲学争论、公共知识传播文本、以及任何“看起来科学/反科学”的判断场景。

## 执行步骤

1. 先看经验锚点：这个主张是否给出可观察、可检验、可反驳的依据。
2. 再看解释形式：它使用了哪些隐喻、模型或原型来组织理解。
3. 对照两层：经验有效不等于解释直观，解释动人也不等于经验成立。
4. 给结论：分别标注其“证据强度”和“可理解性质量”，避免混成一句话。

## 关键规则

- 先分层，再评价。
- 不把“听起来像科学”当作“可检验”。
- 也不把“有隐喻”直接当成“不科学”。

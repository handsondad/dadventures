# 适用场景

适合评估日用品、器械、结构件或新材料方案，尤其适合避免“只看硬度/只看成本”的片面决策。

## 执行步骤

1. 看结构：识别关键微观机制，如位错、晶界、掺杂与界面状态。
2. 看工艺：确认热处理、加工、纯化和后处理会如何改变结构稳定性。
3. 看约束：对照使用场景的强度、腐蚀、触感、寿命、维护和成本要求。
4. 做权衡：明确性能收益与副作用，给出“可接受组合”而非单点最优。

## 关键规则

- 先问场景，再谈优劣。
- 工艺可复制性决定方案可落地性。
- 单指标领先，不代表系统最优。

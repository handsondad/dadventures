# 执行步骤

1. 机制建模：先标注每种材料的主导失效机制与环境耦合路径。
2. 阈值分层：按工况等级设定保守、标准、激进三档阈值区间。
3. 跨材控参：在相同任务与边界条件下比较不同材料，而非跨场景混比。
4. 前兆联判：把裂纹、形变、表面反应等信号纳入统一预警面板。
5. 回写更新：每次维护或失效事件后回写阈值与对照结论，滚动修正规则。

## 关键规则

- 先机制后指标，先区间后单值。
- 不做脱离场景的材料优劣排名。
- 每次结论都标注证据等级与数据缺口。

# 执行步骤

1. 载荷画像：记录真实工况中的循环频率、幅值与关键温湿条件。
2. 耦合映射：识别力学与环境因素的主导交互链，确定优先风险路径。
3. 前兆监测：设置可观测信号，如表面变化、刚度漂移或裂纹早期迹象。
4. 干预迭代：按监测结果调整保护、维护与更换策略，并复盘阈值设置。

## 关键规则

- 先抓主导耦合链，再分配维护资源。
- 先监测前兆，再处理破坏后果。
- 每轮干预都要回写参数，避免经验丢失。

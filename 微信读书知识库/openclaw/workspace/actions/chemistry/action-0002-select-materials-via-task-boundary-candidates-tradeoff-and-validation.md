# 执行步骤

1. 定任务：明确核心功能与失败后果。
2. 设边界：给出硬约束，如成本、寿命、制造条件。
3. 列候选：按机制筛选可行材料与工艺组合。
4. 做权衡：比较性能收益与新增风险。
5. 做验证：用小样或场景测试校准最终方案。

## 关键规则

- 不用单个性能指标拍板。
- 每个候选都写清新增风险。
- 决策记录必须可复盘可复用。

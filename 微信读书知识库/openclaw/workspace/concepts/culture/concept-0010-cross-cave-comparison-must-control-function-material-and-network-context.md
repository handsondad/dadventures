# 核心定义

跨洞窟对照要成立，必须同时标注并控制洞窟功能差异、材料工艺条件与传播网络位置；否则“看起来相似”无法构成可复核结论。

## 关键点

- 先控变量，再谈差异与传承。
- 功能位不同，形制与图像选择可能天然不同。
- 材料约束和网络位置会共同塑造可见风格。

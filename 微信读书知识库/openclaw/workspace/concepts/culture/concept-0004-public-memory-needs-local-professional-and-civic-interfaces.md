# 核心定义

文化记忆的流失常发生在接口处：在地管理缺专业、专业团队缺授权、公众沟通缺共同语言。三者协同，才可能把遗产从“事件性抢救”变为“连续性治理”。

## 关键点

- 接口失配会放大单点错误的破坏范围。
- 公共叙事能力是保护执行力的一部分。

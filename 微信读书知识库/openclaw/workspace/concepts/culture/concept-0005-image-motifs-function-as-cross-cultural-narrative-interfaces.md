# 核心定义

在跨文化传播中，图像母题的作用类似可复用接口：它把复杂观念压缩为可识别、可记忆、可再叙述的公共符号。

## 关键点

- 母题能扩大传播，不等于意义在各地完全不变。
- 图像传播要和文本、仪式、场景一起理解，才不失真。

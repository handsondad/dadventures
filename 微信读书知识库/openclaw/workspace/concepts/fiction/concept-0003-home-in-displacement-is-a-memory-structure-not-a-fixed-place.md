# 核心定义

在流散经验中，家不一定是可返回的地点，而更像由语言、关系和历史经验拼合的记忆结构。人即使定居，也可能持续处在归属错位中。

## 关键点

- 地点可迁移，记忆层级的归属更顽固。
- 身份稳定常依赖叙事整合而不只依赖地理落脚。

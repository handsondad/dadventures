# 核心定义

真正的便宜，不是看一只股票最近涨了多少或跌了多少，而是看它相对于内在价值和基本面到底处在什么估值位置。历史价格只是记忆，不是价值本身；一旦投资人把过去某个高点低点、自己的买入价或者当前仓位当成判断锚点，就很容易被锚定偏见、确认偏误和仓位思维带偏。更稳的做法，是让估值和基本面成为主参考，把涨跌幅和持仓情绪降级为次要信息。

## 为什么重要

- 这个概念能为估值判断提供一个更干净的参照系。
- 它也能帮助识别许多投资错误其实源自心理偏差，而不是分析能力不够。
- 对投资目录来说，这是一张很适合当作认知纠偏器的原则卡。

## 关键判断

- 涨得多不天然等于贵，跌得多也不天然等于便宜。
- 估值和基本面变化，才更能决定一项资产究竟是不是便宜。
- 仓位越重，越要警惕自己开始为立场找论据。

## 常见误解或边界

- 误解一：只要回撤足够大，就有价值。更准确地说，回撤只能说明价格变了，不能说明价值是否匹配。
- 误解二：只要持有时间够长，锚定偏见就会减弱。更准确地说，时间有时反而会加深立场依附。
- 误解三：心理偏差只是新手问题。更准确地说，有仓位的任何人都可能被仓位思维影响。

## 可延展的表达线索

- 可以说，很多人以为自己在做估值，其实只是在回忆价格。
- 更具体一点: 你真正该盯的不是涨跌轨迹，而是价值参照系有没有变。

# 核心定义

好投资的核心，不是你买的资产标签听起来有多好，而是你是否在相对价值足够有利的位置买到了它。投资决策真正的起点应该是价值，而不是价格；判断一项投资值不值得做，不是先看它多热门、多优质，而是先看市场价格相对内在价值是否给出了足够好的条件。一个好资产在高价时可能是坏投资，一个普通资产在低价时反而可能是好投资，所以“买得好”比“买好的”更重要。

## 为什么重要

- 这个概念能把投资判断的重心从资产偏好拉回价格纪律。
- 它也能帮助区分“喜欢一项资产”和“这是不是一笔好投资”这两件事。
- 对投资目录来说，这是一张非常核心的总纲原则卡。

## 关键判断

- 投资收益往往来自价值与价格错位被修正，而不是来自资产名称本身。
- 先估值，再看价格，是更稳的分析顺序。
- 好公司、好行业和好主题，都不能替代好买点。

## 常见误解或边界

- 误解一：只要是优质资产，贵一点也无所谓。更准确地说，价格最终决定回报空间和容错率。
- 误解二：只要价格便宜就是机会。更准确地说，仍需先判断价值，再看价差。
- 误解三：价格纪律会错过伟大公司。更准确地说，价格纪律不是拒绝好公司，而是拒绝为好感付出过高代价。

## 跨书对照

- 这张卡很适合和《投资中最简单的事》的“估值比涨跌更重要”并线：一个强调起点是价值，一个强调不要被价格记忆带偏。

## 可延展的表达线索

- 可以说，投资人赚的不是“押中名字”，而是“买在关系对自己有利的时候”。
- 更具体一点: 好资产只是半个答案，价格才决定剩下半个答案。

# 核心定义

材料不是“成分决定一切”的静态对象。锻打、热处理、掺杂比例、去木质素与后处理等工艺路径，会改变晶体缺陷、界面状态和微观分布，进而系统重写宏观性能。

## 为什么重要

- 它解释了同成分材料为何可表现出巨大性能差异。
- 它将经验工艺与科学机制放进同一框架，便于复用。

## 关键判断

- 评估材料时，工艺历史要和化学组成同等优先。
- 关注可复制工艺，才能从实验效果走向产业效果。

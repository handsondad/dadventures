# 核心定义

有效维护不是固定频次检查，而是围绕主导失效机制配置不同的监测、预防与修复动作。

## 关键点

- 腐蚀、老化、脆断对应不同维护逻辑。
- 维护模板若不区分机制，成本会增加而可靠性未必提升。

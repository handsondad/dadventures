# 核心定义

未完文本虽在叙事上不闭合，但常能暴露世界观的生成过程、机制边界与设定权衡，因此对理解一个虚构世界的“可运行性”价值极高。

## 关键点

- 主线故事给体验，未完材料给机制。
- 世界厚度来自规则一致性与历史层次。

# 核心定义

可交付能力不是产能数字本身，而是各工艺与组织接口在质量、节奏和异常处理上的稳定协同能力。

## 关键点

- 接口不稳，扩产会放大失误而非放大产出。
- 良率治理要追到具体接口而非停留在总量指标。

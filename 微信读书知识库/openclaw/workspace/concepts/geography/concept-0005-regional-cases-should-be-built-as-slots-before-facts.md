# 核心定义

当区域事实不足时，先按空间骨架建立标准化案例槽位，后续再把新增证据逐项回填，比直接写结论更稳健。

## 关键点

- 先保结构连续，再补事实密度。
- 槽位统一有助于跨区域可比性。

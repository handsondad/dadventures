# 核心定义

成熟社会里的很多痛苦，并不只是个人收入下降，而是人还在无意识执行增长时代留下来的默认生活脚本。比如把买房、买车、高教育支出、围绕工资设计全部人生当成理所当然，这些安排在高速增长、预期稳定、年功序列明确的时代也许成立，但在老龄化、长期低增长和高不确定性条件下，就会越来越像自动加压装置。

所以，这个概念的重点不是劝人简单 `省钱`，而是提醒人重新区分 `真实需要` 和 `时代遗留脚本`。同样，制度也要重估是不是还在用增长时代的税制和激励方式惩罚今天最需要流动性的人。作者提出资产税等方案，不一定要全盘接受，但它至少把问题指出来了：成熟社会不能继续假装自己还是工资不断上升的成长型社会。

## 为什么重要

- 它能把很多日常焦虑从私人失败，推进到社会脚本层。
- 它提醒我们，真正需要修改的常常不是个人勤奋程度，而是默认人生模板。
- 它也给后续跨到教育、育儿、工作与地方治理留下接口。

## 关键判断

- 当旧体面方案越来越贵、越来越不稳时，就要怀疑它是不是时代脚本而不是自然真理。
- 成熟社会若继续主要对劳动流量征税，常会放大代际失衡和资产僵化。
- 很多所谓个人选择，其实只是没被看见的默认服从。

## 常见误解或边界

- 误解一：这是在反对买房、教育或长期规划。更准确地说，是要求重估这些安排是否仍然适配当下结构。
- 误解二：成熟社会只需要人更节俭。更准确地说，它更需要重新配置风险、流动性和默认期待。
- 误解三：这只是家庭理财问题。更准确地说，它同时连着税制、教育和代际结构。

## 跨书对照

- 后续适合和《把自己作为方法》对照，看个体怎样识别哪些想法是自己真正的判断，哪些只是外部脚本。
- 也适合和 parenting 目录里的教育、成长压力主题对照，看家庭如何在旧剧本里继续加码孩子。

## 可延展的表达线索

- 可以说，成熟社会真正贵的，不一定是东西本身，而是继续演旧时代的人生。
- 也可以说，很多人不是不会选，而是从未被允许先停下来重估默认项。

# 核心定义

思考工具真正重要，不在于它看起来多深、多专业，而在于它能不能被普通人真正拿来处理现实。也就是说，一个工具只有在进入人的脑子，被自己反复使用、修改、怀疑甚至重建之后，才算真正成为自己的方法。否则它只是外部权威，最多能被引用，不能被运行。

这也是为什么作者强调，今天最需要改变的是 `专家告诉群众` 的旧模式。专家更适合做孵化器、提醒者和激发者，而不是答案发放者。因为如果工具不能被人自己运行，那么一旦离开专家，理解就会再次断掉。

## 为什么重要

- 它把学习从记答案，改写成形成处理世界的能力。
- 它提醒我们，主体性不是先有观点，而是先有能自己运转的工具。
- 它也解释了为什么很多外部知识听起来有道理，但实际改变不了人的判断方式。

## 关键判断

- 真正的方法一定能被人带着走，而不是只能供在外面。
- 不能被自己修改的工具，通常也不能被自己真正使用。
- 专家最有价值的时候，不是替你想完，而是让你开始自己想。

## 常见误解或边界

- 误解一：反对专家模式就是反智。更准确地说，这里反对的是思想外包，不是否定专业知识。
- 误解二：把自己作为方法就是凭感觉。更准确地说，是把工具内化到自己身上。
- 误解三：只要知道概念就等于有方法。更准确地说，方法必须可运行。

- 可以说，真正的工具不是你记住了什么，而是你离开老师后还能怎么想。
- 也可以说，方法的成熟标志不是崇拜它，而是能够改造它。

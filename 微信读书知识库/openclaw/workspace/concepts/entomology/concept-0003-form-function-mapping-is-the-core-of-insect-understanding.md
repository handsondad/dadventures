# 核心定义

理解昆虫的高效路径不是背诵名称，而是建立“形态特征 -> 行为能力 -> 生态作用”的映射链。映射越清晰，识别与解释越稳定。

## 关键点

- 结构差异决定行为可能性边界。
- 观察训练应从可见特征进入，再推断功能。

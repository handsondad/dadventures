# 核心摘要

- 摘录围绕昆虫的共同体征展开：无脊椎、六足、常见四翅，先给出识别边界，再进入功能解释。
- 呼吸与循环系统片段揭示了关键约束：昆虫通过气门与呼吸管交换气体，体型受扩散效率限制，因此不会无限变大。
- 感知与运动片段强调结构特化，如复眼拼接、足部味觉、高速短跑与倒挂动作，说明行为表现由器官设计驱动。
- 生命周期与社会性片段显示策略多样：蜉蝣短命繁殖、熊蜂越冬、胡蜂育幼分工、蚂蚁协作与寄生蜂的生态控制。
- 因而可复用主线是：结构约束 -> 功能分化 -> 行为策略 -> 群体分工 -> 生态作用。

- 可搜索短句：昆虫只有六条腿

## 可拆出的概念卡

- 生物体设计受约束驱动，结构限制直接塑造能力边界。
- 昆虫个体虽小，但通过分工与数量形成生态系统关键支撑。

## 可拆出的动作卡

- 用五步法读昆虫知识：结构、约束、行为、分工、生态功能。

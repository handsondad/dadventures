# 核心摘要

- 第二批摘录把首批“结构约束”推进到“形态-行为映射”：六足、复眼、呼吸孔、口器与翅的差异，直接对应移动、觅食、躲避和繁殖策略。
- 互惠与控制线更突出：蚂蚁搬种子、寄生蜂抑制种群、群居蜂类分工，显示昆虫不是孤立个体，而是生态网络中的协作与制衡节点。
- 观察训练线更可操作：通过“腿数、身体分段、口器与翅型、行为场景”可快速完成初步辨认，避免把蜘蛛等非昆虫误归类。
- 数据尺度线（如鸟类食虫量级）提醒：小体型并不意味着小影响，生态稳定常由高密度小节点维持。
- 因而第二批可复用主线是：形态识别 -> 行为推断 -> 生态位判断 -> 命名归类 -> 系统影响评估。

## 原始定位

- 可搜索短句：所有昆虫都有六条腿
- 可搜索短句：昆虫没有肺 而是呼吸孔和管道
- 可搜索短句：蚂蚁把种子放在一边 对植物完美
- 可搜索短句：寄生蜂保证其他物种不会太多

## 可拆出的概念卡

- 昆虫学习的关键是形态与行为的一一映射，而非零散知识点记忆。
- 生态系统稳定依赖协作与控制并存的多样化小节点网络。

## 可拆出的动作卡

- 用五步观察法做昆虫识别与生态判断：形态、行为、场景、归类、系统作用。

# 核心摘要

- 第四批承接第三批的“反宣传表达”，把焦点从单人写作推进到多人对话：当立场冲突不可避免时，如何修复误解并形成最小可执行共识。
- 现有摘录提供三组直接锚点：其一，文本强调“哲学家不是宣喻真理，而是为结论提供论证”，这为跨立场讨论提供共同程序标准；其二，“文本并列杂陈使差异清楚摆在面前”提示对话应先做版本澄清而非直接归因；其三，“宣传任务不是客观研究真理”说明误解常来自情绪动员与单面叙事。
- 因此第四批可复用主线是：误解定位 -> 语义修复 -> 最小共识收敛 -> 分歧托管。
- 这里的最小共识不是价值统一，而是对可检验命题、证据边界和暂行行动的有限一致。
- 证据边界说明：当前原始摘录未给出完整对话案例，本批输出可复核的修复与共识规则，不扩写具体人物情境。

## 原始定位

- 可搜索短句：哲学家不是宣喻真理 他为自己的结论提供论证
- 可搜索短句：有了文字文本就不同了 不同观念体系之间的差异都清楚地摆在我们面前
- 可搜索短句：在非实用的领域 求真是一种边缘的要求
- 可搜索短句：宣传的任务可不是对真理进行客观的研究

## 可拆出的概念卡

- 误解修复优先于立场反驳，是跨立场对话的第一生产力。
- 最小共识应定义为“共享可检验命题 + 共享边界 + 共享下一步动作”。

## 可拆出的动作卡

- 用四步法推进跨立场对话：对齐版本、校准语义、收敛共识、托管分歧。

# 核心摘要

- 第二批把首批的理性态度定义推进到判断纪律：在现实讨论里，常识不是反理论，而是经验校准的起点，用于筛掉脱离现实代价的空洞论述。
- 书中多处提示要区分层级：经验可检验的问题、解释框架的问题、价值宣传的问题，不同层级混写会制造伪争论。
- 对理论演进，重点不在“一次证伪就终结一切”，而在“更成功理论取代旧理论”的历史链路，这要求同时比较解释力、可检验性和继承关系。
- 对公共传播，情绪动员与求真机制常处于张力中；若不先划清边界，理性讨论会被宣传逻辑替代。
- 因而第二批可复用主线是：常识校准 -> 经验检验边界 -> 解释层级纪律。

## 原始定位

- 可搜索短句：理性态度是一种重常识 重经验的态度
- 可搜索短句：平常说话中的全称命题都包含推测 推论
- 可搜索短句：证伪并不能毁灭一个理论
- 可搜索短句：宣传的任务可不是对真理进行客观的研究

## 可拆出的概念卡

- 理性讨论首先要做层级分离，而不是立场对冲。
- 理论更替是连续比较过程，不是单次胜负判决。

## 可拆出的动作卡

- 用五步法评估知识主张：校准、分层、检验、比较、沟通。

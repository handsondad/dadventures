# 核心摘要

- 第三批从“星期五的教育”切入，把《鲁滨逊》主线推进到人际与秩序层：生存不再是单人优化，而是进入权力分配、解释框架与协作制度的问题。
- 现有摘录可直接支撑两点：其一，鲁滨逊已形成对越权暴力的反思（我有什么权力扮演法官和执行官）；其二，文本明确出现“宗教神秘化以维持神职权威”的观察，这为理解教育关系中的权力结构提供入口。
- 因此第三批可复用主线是：先界定权力边界 -> 再做文化翻译 -> 最后建立可持续协作秩序。
- 证据边界说明：当前导出中关于星期五互动的可检索摘录较少，本批以“最小可证据骨架”建模，避免扩写到不可回溯细节。

## 原始定位

- 可搜索短句：我有什么权力或理由去扮演法官和执行官
- 可搜索短句：存在着把宗教神秘化的手段 以保持人们对神职人员的尊重
- 可搜索短句：这些人并没有伤害我

## 可拆出的概念卡

- 跨文化协作先要把“控制关系”转为“边界清晰的角色关系”。
- 文化翻译不是灌输一致性，而是建立可共享的解释接口与行动规则。

## 可拆出的动作卡

- 在跨文化协作场景使用四步法：权力盘点、翻译对齐、协作试运行、边界复盘。

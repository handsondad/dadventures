# 核心摘要

- 第三批在证据稀疏条件下补“区域案例槽位”而非补“区域事实细节”：当前唯一硬锚点仍是北中南三条山脉主带。
- 可直接推进的是方法结构：先按三主带预置案例槽位，再在每个槽位下分层记录地形约束、水系问题、人地协同假设与已证事实。
- 这使“区域案例补足”从一次性写实转为增量回填流程，既满足连续推进，也避免把假设误写成事实。
- 人地协同判断在本批中被定义为“问题生成层”，仅输出可验证问题，不输出未被摘录支持的地区结论。
- 因而第三批可复用主线是：槽位预置 -> 约束落图 -> 证据分层 -> 案例增量回填。

## 原始定位

- 可搜索短句：北边的天山 阴山 燕山
- 可搜索短句：中间的昆仑山 秦岭 大别山
- 可搜索短句：南边的喜马拉雅山 苗岭 南岭

## 可拆出的概念卡

- 区域案例应在证据稀疏时先建槽位，再补事实。
- 地形与水系约束应先落图为方向性结构，再进入具体地名细节。

## 可拆出的动作卡

- 用四步法做地理案例增量构建：建槽位、画约束、分证据、滚动回填。

## 备注

- 当前批次不新增地名级事实断言；待后续原始摘录增量后再转为区域事实卡。

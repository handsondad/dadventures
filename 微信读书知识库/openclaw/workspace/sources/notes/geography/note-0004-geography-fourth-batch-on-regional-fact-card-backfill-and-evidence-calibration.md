# 核心摘要

- 第四批在第三批“槽位先行”的基础上推进到“事实卡回填规则”：重点不是新增大量地理事实，而是把已有锚点按证据层级写成可持续扩展的区域事实卡。
- 当前导出可证据锚点仍集中在三条山脉主带：北边天山-阴山-燕山，中间昆仑山-秦岭-大别山，南边喜马拉雅山-苗岭-南岭。
- 因此第四批可复用主线是：锚点入卡 -> 证据分级 -> 不确定性标注 -> 增量回填。
- 该主线可把“材料太少”转换为“事实卡结构够稳”：后续每有新摘录，只需按槽位补入并调整证据等级。
- 证据边界说明：本批不新增未在原始摘录出现的区域细节，不输出地名级扩展判断。

## 原始定位

- 可搜索短句：北边的天山 阴山 燕山
- 可搜索短句：中间的昆仑山 秦岭 大别山
- 可搜索短句：南边的喜马拉雅山 苗岭 南岭

## 可拆出的概念卡

- 证据层级校准决定区域事实卡的可靠性与可扩展性。
- 不确定性标签是地理学习里防止“假定成真”的必要接口。

## 可拆出的动作卡

- 用四步法回填地理事实卡：锚点登记、等级标注、空槽提问、迭代更新。

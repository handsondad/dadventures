# 核心摘要

- 第五批承接第四批的“锚点入卡-分级标注”主线，进一步推进到维护层：同一套区域事实卡如何互证，以及出现冲突时如何消解而不破坏框架稳定性。
- 当前摘录仍只提供三条山脉主带锚点（北：天山-阴山-燕山；中：昆仑山-秦岭-大别山；南：喜马拉雅山-苗岭-南岭），这意味着互证不能靠增添新事实，而要靠“卡片内部一致性+跨卡结构一致性”来执行。
- 因此第五批可沉淀最小规则链：锚点一致性检查 -> 证据等级对齐 -> 冲突条目挂牌 -> 暂行结论与待证问题并存。
- 冲突消解策略是“先降级、后验证、再升级”：若新旧表述冲突且证据不足，先把强结论降为待证，不做强行裁决。
- 证据边界说明：当前原始导出无额外区域细节，本文仅建立互证与冲突处理协议，不新增地名级或机制级新事实。

## 可拆出的概念卡

- 事实卡互证的核心是锚点一致性和标签一致性，而非文本重复。
- 冲突消解应优先采用证据等级回退，而不是叙事性裁决。

## 可拆出的动作卡

- 用五步法处理冲突：定位冲突、等级回退、并行记录、待证提问、复核升级。

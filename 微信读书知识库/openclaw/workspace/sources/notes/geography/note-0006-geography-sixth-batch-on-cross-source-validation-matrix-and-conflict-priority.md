# 核心摘要

- 第六批承接第五批的“互证与冲突治理”，继续把流程从原则推进到可排程执行：先把互证对象放进统一矩阵，再按冲突优先级分配复核顺序。
- 在当前来源条件下，核心锚点仍是三条山脉主带（北：天山-阴山-燕山；中：昆仑山-秦岭-大别山；南：喜马拉雅山-苗岭-南岭）。
- 因为原始摘录信息粒度很粗，第六批不新增地理事实，而是新增一套矩阵字段：来源类型、锚点一致性、主张粒度、证据等级、冲突状态、下一次复核窗口。
- 冲突优先级不按“谁先出现”排序，而按三项合成：影响范围、误判可逆性、证据缺口大小。这样能把有限复核时间先投入高价值冲突。
- 证据边界说明：本文仅对治理协议加厚，不扩写超出原始摘录的新地点、新因果或新机制。

- 可搜索短句：中间的昆仑山 秦岭 大别山
- 可搜索短句：南边的喜马拉雅山 苗岭 南岭

## 可拆出的概念卡

- 跨来源互证需要矩阵化字段，而不是叙事性比对。
- 冲突优先级应按影响、可逆性和证据缺口联合决定。

## 可拆出的动作卡

- 用“建矩阵-挂冲突-排优先级-定窗口-复核回写”五步循环维护区域事实卡。

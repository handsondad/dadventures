# 核心摘要

- 这批摘录最清晰的一条线是：航天员不是“飞得好”即可，而是多重条件叠加的高风险岗位。选拔逻辑强调既有飞行经验、心理承受能力、持续训练能力与任务执行可靠性。
- 第二条线是训练方法。书中反复强调主动学习、规律化练习、把压力转成动力、通过工具化手段持续复盘，说明高水平表现来自长期可重复训练机制，而非临场天赋。
- 第三条线是极端环境适应。失重错觉、空间运动不适、睡眠与心理波动等细节显示，太空任务不仅是技术任务，也是生理心理协同任务。
- 第四条线是系统工程意识。从个体执行到多系统管理，再到载人航天三步实施，个人成长被嵌入国家级长期工程节奏。
- 因此首批可落地框架是：选拔标准 -> 训练闭环 -> 极端适应 -> 系统任务，四段共同解释“英雄叙事”背后的可复制结构。

## 可拆出的概念卡

- 高风险岗位能力是选拔机制与长期训练共同产物。
- 极端环境中的表现由技术能力与心理生理调节共同决定。

## 可拆出的动作卡

- 用“选拔-训练-适应-系统任务”四段法评估高风险职业成长路径。

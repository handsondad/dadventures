# 核心摘要

- 当前摘录显示两条互补主线：陈寅恪强调“自由之思想、独立之精神”的学术底线，傅斯年强调“史料与方法”的制度化学术路径。
- 陈寅恪相关段落反复出现同一原则：不能预设意识形态结论再做研究，学术人格先于立场迎合。
- 傅斯年与史语所线索给出另一面：口号之外要靠方法、材料和组织能力，把史学推进到可检验、可积累的研究实践。
- 文本还提示第三层：学术不只产论文，也承担文化记忆与公共精神的长期保存，故“亡史之痛”与“独立精神”被放在同一问题域。
- 因而首批可复用主线是：学术人格底线 -> 证据与方法路径 -> 机构化执行 -> 文化记忆承接。

## 可拆出的概念卡

- 学术独立首先是研究前提独立，而非结论姿态独立。
- 高质量学术共同体需要“人格底线 + 方法制度”双支柱。

## 可拆出的动作卡

- 用四步法评估一个学术项目：前提是否先验化、证据是否可检验、组织是否可持续、产出是否可传承。

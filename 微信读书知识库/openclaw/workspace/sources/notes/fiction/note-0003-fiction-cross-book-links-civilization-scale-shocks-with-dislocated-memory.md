# 核心摘要

- 把《三体》和《台北人》并置后，最有价值的不是题材差异，而是共同问题：人在超出掌控的结构变化中如何重建判断与尊严。
- 《三体》提供“宏观冲击”维度：技术尺度与生存竞争会快速重排伦理与制度边界。
- 《台北人》提供“微观侵蚀”维度：时间推进与历史位移会慢速改写身份、记忆与体面结构。
- 两本合并后的统一判断是：无论变化来自外部危机还是内部流逝，核心挑战都在于边界感、谦卑感与叙事自我修复能力。
- 因而可复用主线是：尺度冲击 -> 身份位移 -> 认知校准 -> 叙事修复 -> 行动选择。

## 可引用线索（短锚点）

- 弱小和无知不是生存障碍 傲慢才是
- 毁灭你 与你有何相干
- 今昔之比
- 小说里的真实 是教人看起来觉得真

## 我的想法

- 这组跨书整合把 fiction 目录从“科幻/现实题材分离阅读”推进到“尺度与时间双维判断框架”。
- 对外最可复用的一句是：真正压垮人的，常不是单一事件，而是尺度突变与时间侵蚀共同造成的认知失配。

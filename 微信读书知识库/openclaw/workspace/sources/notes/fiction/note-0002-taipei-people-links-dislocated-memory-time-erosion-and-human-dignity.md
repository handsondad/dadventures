# 核心摘要

- 当前摘录最稳定的线索是“今昔之比”：过去与现在并置，不只是审美怀旧，而是社会结构、文化价值与个体命运的断裂表达。
- 《金大班的最后一夜》片段把宏观变迁压进具体身体与情感经验，体现“灵与肉”“尊严与处境”的不可简化张力。
- 附录中的时间论断（青春不可留、功名终归空）将小说群像连接到更普遍的人生问题：时间推进下的身份褪色与意义重估。
- 关于“家”的表述显示流散经验的核心：家不再是单一地点，而是记忆拼合体；这使人物长期处于空间归属与精神归属的错位中。
- 因而首批可复用主线是：历史位移 -> 今昔张力 -> 身份错位 -> 时间侵蚀 -> 叙事中的人性真实。

- 可搜索短句：今昔之比

## 可拆出的概念卡

- 流散叙事中的家常是记忆结构而非地理坐标。
- 文学真实性不是事实复刻，而是情感与人性机制的可感真实。

## 可拆出的动作卡

- 读位移文学时用五步法：时代断裂、人物处境、时间压力、记忆机制、叙事真实。

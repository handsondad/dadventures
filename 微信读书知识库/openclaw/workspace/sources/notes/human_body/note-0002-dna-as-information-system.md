# 核心摘要

- 当书写到四种碱基、配对规则、双螺旋和半保留复制时，DNA 的关键特征开始清晰起来：它不只是携带信息，更天然支持复制、校对和代际延续。
- 两条链的信息等价、A-T 与 C-G 的朴素配对规则、三碱基密码子的节约性，一起把生命从“神秘物质”转换成“可编码、可复制、可执行的信息系统”。
- 这里真正动人的地方不是名词本身，而是简洁结构如何支撑复杂生命：四种碱基的组合就能产生极大的信息容量，配对规则又让复制变得可行。
- 对后续内容准备来说，这一段非常适合做“为什么生命可编辑”这个问题的底层解释，因为编辑的前提正是编码和复制都足够稳定。

## 可引用片段

- `两条链所携带的信息是完全等同的`：适合讲“双螺旋不是漂亮图案，而是复制逻辑”。
- `DNA 半保留复制模型`：适合用来说明生命延续并不神秘，而是有明确机制。
- `三碱基密码子`：适合用来引出“生命在无数可能中选择了一种既多样又节约的编码方式”。

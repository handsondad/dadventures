# 核心摘要

- 第二批把首批“能量与内共生模块”推进到“生态运营层”：植物不是静态生产者，而是在防御、协作、竞争和扩散上持续做策略组合。
- 地衣与多体共生段落说明：植物相关系统常通过跨物种接口提升环境耐受与拓殖能力，协作不是例外而是常态机制。
- 海带与“并非只有植物才能光合”的线索提醒：功能能力可以跨类群出现，分类边界不等于功能边界，判断应以机制而非名称为中心。
- 竞争与信号线可抽象为“低速高时延博弈”：植物通过化学信号、结构分层与资源分配在长期竞争中获得优势，而非靠短时机动。
- 因而可复用主线是：防御分层 -> 协作扩散 -> 资源竞争 -> 信号调度 -> 生态位稳固。

## 原始定位

- 可搜索短句：真菌与蓝细菌的联手几乎是必然会发生的事情
- 可搜索短句：地衣并不是一种植物 而是自己组成了一个生态系统
- 可搜索短句：不是只有植物才能进行光合作用
- 可搜索短句：只要给生命充足的时间 它就可以给地球一个惊喜

## 可拆出的概念卡

- 植物优势来自防御分层与慢变量竞争，而非单点能力。
- 生态扩张依赖协作接口与功能跨界，而非物种标签本身。

## 可拆出的动作卡

- 用五步法观察植物策略：防御、协作、扩散、竞争、信号。

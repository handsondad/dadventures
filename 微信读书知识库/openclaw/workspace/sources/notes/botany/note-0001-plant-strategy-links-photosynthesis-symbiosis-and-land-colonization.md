# 核心摘要

- 摘录主线强调：植物选择不动并非低级，而是能量与资源策略上的高效解法。
- 蓝细菌相关片段显示，光合作用并非植物天生技能，而与远古内共生事件紧密相关；叶绿体起源争论最终由分子证据推动收敛。
- 关于基因横向转移与内共生的叙述，给出一个重要演化视角：复杂功能可通过模块组合加速出现，而非仅靠缓慢线性变异。
- 地衣段落把这一逻辑落实到陆地开拓：真菌与蓝细菌的互补协作突破干旱与矿物利用约束，推动土壤形成与后续生态基础建设。
- 因此可复用主线是：能量获取策略 -> 共生模块化 -> 环境突破 -> 生态工程效应。

# 核心摘要

- 当前摘录显示一条强主线：诅咒在托尔金叙事中不只是情节事件，而是可跨代持续施压的结构装置。
- 胡林与图林相关片段把命运压力落实为心理后果：人在恐惧与愤怒中会做出更易放大悲剧的反应。
- 甘道夫与萨茹曼细节提供另一种力量伦理：掌握信息与优势时仍克制羞辱他人的冲动，这构成角色品格的隐性高度。
- 译后记揭示《未完的传说》的方法价值：它以未完成文本补齐世界底层逻辑，使中洲从故事集合升级为可持续推演的历史-文化系统。
- 因而首批可复用主线是：诅咒机制 -> 心理受压 -> 行动偏转 -> 品格分野 -> 世界构建加深。

## 可拆出的概念卡

- 诅咒可被理解为跨代叙事约束机制。
- 未完文本对世界观建设的价值在于补机制而非补剧情。

## 可拆出的动作卡

- 读未完史诗材料时用四步法：约束机制、心理反应、伦理细节、世界补缀。

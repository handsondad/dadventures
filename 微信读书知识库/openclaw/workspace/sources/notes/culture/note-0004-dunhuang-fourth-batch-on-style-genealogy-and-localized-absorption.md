# 核心摘要

- 第四批把第三批的“母题与分层”进一步推进为“断代谱系与地方化吸收”：关注风格如何在时间上连续演变，以及外来模板如何被本地材料与制度改写。
- 现有摘录提供三组可证据锚点：其一，莫高窟有明确年代点位（如第254窟标注北魏）并存在多种窟形，支持断代比较；其二，366年开窟、北凉僧人北迁并影响云冈，提示风格与制度网络具有跨区域传递链；其三，敦煌彩塑受西北材料约束并与克孜尔及中亚技法一致，说明“传播一致性”与“地方材料适配”并存。
- 因此第四批可复用主线是：断代样本定位 -> 跨区传播链校验 -> 地方化吸收识别 -> 谱系化表达。
- 证据边界说明：当前导出摘录仍偏框架与例示，尚不足以做细粒度朝代内微风格分期，本批先建立可回填的谱系模板。

## 可拆出的概念卡

- 断代风格谱系应以可定位样本和传播链证据为骨架，而非仅凭朝代标签。
- 地方化吸收不是被动复制，而是外来模板在本地材料、功能与机构条件下的重写。

## 可拆出的动作卡

- 用四步法建立遗产风格谱系：锚点建表、传播校验、本地约束标注、吸收类型判定。

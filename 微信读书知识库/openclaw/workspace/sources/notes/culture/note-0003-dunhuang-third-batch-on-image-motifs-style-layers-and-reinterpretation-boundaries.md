# 核心摘要

- 第三批把敦煌从“保护治理”继续推进到“图像阅读方法”：关注母题如何传播、风格如何分层、再阐释边界如何设定。
- 现有摘录支持三条线索：其一，《法华经》观音形象广泛传播，显示宗教母题具备高复制性叙事接口；其二，中心柱窟、大像窟、涅槃窟等形制并存，提示风格与功能存在分层；其三，彩塑技法与河西到中亚的一致性，显示图像生产受材料与工艺网络共同约束。
- 因而第三批可复用主线是：母题传播机制 -> 风格分层约束 -> 再阐释边界管理。
- 证据边界说明：当前导出更偏结构与例示，尚不足以支撑细粒度断代风格谱系；本批先建立可证据的分析框架。

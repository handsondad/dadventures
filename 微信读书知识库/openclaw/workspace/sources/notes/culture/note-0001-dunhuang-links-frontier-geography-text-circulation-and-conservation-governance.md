# 核心摘要

- 摘录显示敦煌首先是地理与制度节点：位于河西走廊西端，连接中原与西域，是陆上丝路的重要门户。
- 其文化繁荣并非孤立形成，而是由交通网络、译经活动与宗教传播共同驱动，典型如鸠摩罗什译经体系与石窟传播链。
- 石窟系统的形成与延续具有明确环境逻辑：城市寺院利传播，山中石窟利修行与避灾，反映宗教实践与风险管理的双重需求。
- 摘录也集中呈现了保护失序带来的破坏：不专业修复、洞窟打通、战争与临时管理失当都能造成不可逆损伤。
- 因而可复用主线是：边地节点 -> 交流网络 -> 物质化载体 -> 治理质量 -> 文明记忆保存结果。

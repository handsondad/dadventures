# 核心摘要

- 第六批承接第五批“微观断代矩阵+跨洞窟对照”，继续推进到维护层：当不同来源或不同卡片出现冲突特征时，如何互证并按优先级处理。
- 当前摘录可支持三类互证锚点：其一，年代与窟形锚点（如“中心柱窟第254窟北魏”“大像窟/涅槃窟”）；其二，传播网络锚点（“366年开窟”“凉州僧人北迁并影响云冈”）；其三，工艺与材料锚点（敦煌彩塑与克孜尔/中亚技法一致，且受西北材料约束）。
- 这些锚点天然可能出现冲突：同一特征可能被解释为“传播继承”或“功能/材料收敛”。因此第六批沉淀最小规则链：跨源对齐 -> 冲突挂牌 -> 优先级裁决 -> 证据回写。
- 冲突优先级建议按三维排序：影响范围、证据强弱、可验证性。
- 证据边界说明：当前导出没有逐窟全量记录，本批只建立互证与裁决协议，不输出超出摘录的新断代结论。

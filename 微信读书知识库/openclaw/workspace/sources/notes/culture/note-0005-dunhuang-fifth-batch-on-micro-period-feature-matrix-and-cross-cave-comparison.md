# 核心摘要

- 第五批承接第四批的谱系框架，继续推进到可执行比较层：把零散断代线索转成“微观特征矩阵”，并通过跨洞窟对照降低单点误判。
- 现有摘录可支持三组关键锚点：其一，中心柱窟第254窟标注北魏，且同书提到大像窟、涅槃窟等不同窟形，说明至少可做“年代-窟形”微观对照；其二，敦煌开窟与凉州僧人北迁、云冈开凿之间存在传播链，且内地多地石窟并列出现，支持跨区域对照视角；其三，敦煌彩塑受西北材料条件约束，但制作工艺与克孜尔及中亚一致，提示“地方约束 + 区域共技”可并存。
- 因此第五批可沉淀最小方法链：建立特征矩阵（年代锚点、窟形、工艺、功能）-> 做跨洞窟对照 -> 标注传播与地方约束 -> 按证据等级输出判断。
- 证据边界说明：当前导出不含大量洞窟逐窟细节，尚不足形成完整时序数据库；本批定位为“比较框架与字段模板”，待后续摘录回填。

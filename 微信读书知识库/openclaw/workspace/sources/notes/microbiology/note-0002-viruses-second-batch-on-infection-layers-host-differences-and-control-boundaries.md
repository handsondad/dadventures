# 核心摘要

- 第二批把首批“受体-复制-免疫”链条进一步分层：暴露与进入、细胞内复制、释放传播、宿主免疫反应、组织损伤与恢复，是一条连续决策链。
- 同一种病毒在不同个体中的后果差异，往往来自宿主状态与免疫反应阈值差异，而不只是“病毒强弱”单变量。
- 裂解释放与出芽释放提供了不同的细胞与传播后果：前者常伴随更直接细胞破坏，后者更可能形成持续感染贮主。
- 症状并不总是病原体直接损伤的镜像，免疫细胞因子可放大不适，这提示防控与治疗要区分“控复制”与“控炎症”目标。
- 因而第二批可复用主线是：感染链路分层 -> 宿主反应分型 -> 防控决策边界。

## 原始定位

- 可搜索短句：只能感染表面有CD4分子的细胞
- 可搜索短句：新生病毒在最后破茧而出时难免会杀死宿主细胞
- 可搜索短句：新生病毒也可能以出芽的方式更平缓地穿过细胞膜
- 可搜索短句：典型非特异性症状通常并非由入侵微生物引起

## 可拆出的概念卡

- 病毒结局应按感染链路分层，而不是单点归因。
- 防控决策要同时管理病原复制风险与宿主反应代价。

## 可拆出的动作卡

- 用五步判断法评估病毒事件：暴露、复制、反应、损伤、边界。

## 备注

- 第二批已形成机制化判断框架，后续第三批可补“病毒演化速度与公共沟通误差管理”。

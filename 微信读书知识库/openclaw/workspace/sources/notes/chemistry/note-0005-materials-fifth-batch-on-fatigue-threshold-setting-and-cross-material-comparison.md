# 核心摘要

- 第五批承接第四批的疲劳与耦合损伤主轴，继续推进到两个执行难点：阈值如何设，跨材料如何比。
- 现有摘录可回溯三组锚点：其一，钢中碳含量过高会显著脆化（如“约4%而非1%”导致易碎），而武士刀工艺通过高碳/低碳分区实现“刀锋硬+刀身韧”，说明阈值不是单值，而是“任务-部位-机制”联动设定；其二，不锈钢依赖氧化铬保护膜与自修复机制，纸张老化受木质素光氧化影响，混凝土强度来自持续水化与微结构演化，说明不同材料的损伤起点与演化速率不可直接类比；其三，混凝土偏脆性断裂、钢可通过组织与成分调配获得韧性窗口，提示跨材料对照应采用机制字段而非统一强度口径。
- 因此第五批可形成最小方法链：机制锚定 -> 阈值区间设定 -> 跨材料控制对照 -> 证据分级更新。
- 证据边界说明：当前导出没有标准疲劳曲线与S-N数据，本批仅建立机制化阈值规则与对照模板，不扩写数值寿命结论。

## 原始定位

- 可搜索短句：比例达到百分之四而非百分之一 形成的钢就会极为易碎
- 可搜索短句：高碳钢制成的刀剑在战斗中很容易折断
- 可搜索短句：氧化铬是透明坚硬的矿物质 保护膜会自我修复
- 可搜索短句：木质素遇到光会和氧发生化学作用
- 可搜索短句：混凝土凝固时会和水作用 引发连锁化学反应

## 可拆出的概念卡

- 疲劳阈值应设为机制约束下的区间，而非脱离场景的单一常数。
- 跨材料对照要先统一机制字段，再比较阈值窗口与失效路径。

## 可拆出的动作卡

- 用五步法做阈值与对照：机制建模、阈值分层、跨材控参、前兆联判、回写更新。

# 书籍定位

这本书最适合接进 economics 目录的地方，不是把它读成婚恋趋势评论，而是把现代社会怎样在消费主义、都市化和后物质主义条件下重写生活单位压出来：婚姻不再默认，单人居住变得可行，隐私被商品化，而原本由家庭兜底的支持功能开始迁向更分布式的关系网络。

## 为什么值得整理

- 它能把 economics 当前的 `消费资格/时间资格/商品差异制度`，进一步接到 `关系、居住和支持单位` 这一层。
- 它适合解释为什么消费社会会自然外溢到不婚、独居和家庭单位变化。
- 它也天然适合继续外接 `独居安全感/网络社会/照料与支持节点` 等后续主题。

## 计划拆出的主题

- 隐私、独立和单人居住怎样被资本主义与消费社会做成可偏好的生活方式
- 孤独为什么不能被压成婚姻问题，以及支持为何要从家庭单位迁往关系网络
- 独居人群怎样依靠可调用的陪伴、社交和时间节点获得社会安全感
- 家庭单位社会怎样转向网络和人力节点社会，并把支持拆成更多接口
- 后物质主义和需求阶梯变化怎样继续重写婚姻、独居与自我实现的关系

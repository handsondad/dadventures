# 书籍定位

这本书已从 `started` 提升为 life_wisdom 的第五本 `active`。最初拆解不追求概括 38 封信，而是先固定一条可复用主线：`从索取转向创造 -> 命运由行动改写 -> 好运可以被策划 -> 工作与立即行动把主体性做出来`。

现在这条线又继续补出第二批与第三批，已经延长成一条更完整的单书 spine：`主动创造与启动 -> 竞争中的不断线 -> 借口、自我认知、目标与赢家态度组成的竞争心智`。

## 为什么值得整理

- 原始导出有 130 条笔记，前四封信就足以落成一批真实的 `source_note -> concept -> action -> collection -> idea` 闭环。
- 它为 life_wisdom 补上一条和 `自由/幸福/责任与秩序` 不同的支线：不是先问怎样更稳或更幸福，而是先问怎样从被动等待改成主动创造。
- 这条线也能自然接到后续第二批的 `竞争决心/信念/不放弃/忠于自己`，适合继续加厚而不必泛化成成功学摘抄。
- 第三批继续补出的 `防止借口 / 自我认知 / 目的主义 / 赢家态度`，让这本书开始具备比泛泛励志更稳定的竞争判断框架。

## 计划拆出的主题

- 创造者心态如何把人从出身决定论和索取心态里拉出来
- 好运为什么更像可被策划和引导的结果，而不是只能等待的偶然
- 工作态度与立即行动如何压过惰性，把机会变成现实进展
- 竞争决心、精神资本、不主动放弃、信念与自我忠诚如何把启动能力延长成长期韧性
- 借口怎样让人自我封锁，自我认知怎样决定选择和行动，目标与赢家态度怎样影响竞争结果

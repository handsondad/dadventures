# 对照轴线

`当推进卡住时，先判断主故障属于哪一类：幸福结构失配、秩序底盘失稳，还是竞争姿态掉线。`

这张 comparison_pack 不新增书内事实，只调用三条已存在 spine：

- 《幸福的方法》：`note-0100 -> concept-0103/0104 -> action-0054`
- 《人生十二法则》：`note-0101 + note-0105 -> concept-0105/0106/0114/0115 -> action-0055/0059`
- 《洛克菲勒留给儿子的38封信》第三批：`note-0104 -> concept-0111/0112/0113 -> action-0058`

## 最小可复用比较

1. 幸福的方法（校准类）
   - 主要回答：目标是否同时满足过程体验与长期意义。
   - 典型信号：达成后空心、长期用“以后再幸福”透支当下。
   - 首选动作：`action-0054`。

2. 人生十二法则（托底类）
   - 主要回答：人在混乱期是否还有可执行秩序与责任承接。
   - 典型信号：作息散乱、边界失守、抱怨和无力感上升。
  - 首选动作：若整体失序先 `action-0055`，若关系边界与长期纪律反复断线优先 `action-0059`。

3. 洛克菲勒第三批（推进类）
   - 主要回答：人是否先用借口、自我看低和目标失焦把自己移出赛场。
   - 典型信号：拖延分心、解释很多、下一步动作概率持续下降。
   - 首选动作：`action-0058`。

## 决策路由规则（可直接复用）

1. 先判主故障，不先看情绪强弱
   - 若问题是“目标本身不值得长期投入”，先走幸福校准（`action-0054`）。
  - 若问题是“人已失序、执行底盘塌陷”，先走秩序托底（`action-0055`）。
  - 若问题是“边界模糊 + 纪律断线反复”，优先走托底第二层（`action-0059`）。
   - 若问题是“目标清楚但持续自我封锁”，先走竞争推进（`action-0058`）。

2. 先托底再推进
  - 当 `睡眠/节律/边界` 明显失稳时，不直接上竞争推进，先用 `action-0055` 恢复最小秩序；若仍反复断线，再用 `action-0059` 稳定边界与纪律，再切 `action-0058`。

3. 先校准再加压
   - 当目标长期只剩外部评价驱动时，不直接加执行强度，先用 `action-0054` 重新筛选目标，再决定是否进入 `action-0058`。

4. 三者不可互相替代
   - `action-0054` 解决的是“值不值得持续做”。
  - `action-0055/0059` 解决的是“有没有稳定底盘做，以及边界和纪律能否长期不断线”。
   - `action-0058` 解决的是“会不会把自己先锁死而做不出来”。

## 调用顺序建议

1. 用一句话写当前主故障：`失配 / 失稳 / 自锁`。
2. 只启动对应一本书的一张动作卡，先跑 24-72 小时。
3. 若无改善，再按“托底 -> 校准 -> 推进”顺序串联第二张动作卡。

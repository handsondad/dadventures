# 本批主线

1. 历史位移把家从地点改写为记忆结构。
2. 时间侵蚀把荣耀与青春推向不可逆褪色。
3. 文学通过可感真实把时代压力转译为人性经验。

## 可调用结论

- 读《台北人》最可迁移的价值是“用人物经验理解时代断裂”，而不只停在怀旧情绪。

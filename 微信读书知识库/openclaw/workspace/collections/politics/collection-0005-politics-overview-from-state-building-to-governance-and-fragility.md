# 主题说明

这版对外短稿只做一件事：把 politics 目录压成一条可复用的六段链路，而不是继续堆制度名词。

六段链路如下：

1. 国家先被压实（收权与编格）
2. 资源被压成能力（工业化与计划体制）
3. 强动员可能放大高风险试验（反馈与退出不足）
4. 系统可能自我毁伤，也可能通过市场/专业/思想空间恢复弹性
5. 成熟阶段转向治理分工（外部性、信息复杂性、激励相容）
6. 国家能力变强，不自动等于社会稳定（自由、责任与纠错机制仍是硬约束）

新增的 `collection-0012` 与 `collection-0013` 把第 5、6 段接得更实：改革后半程的问题会从“增长速度”转为“市民化承接”，而承接能力又直接受财政-土地-公共服务接口约束。

一句话总结：

政治阅读最稳的顺序，不是先问立场，而是连续追问“国家怎么形成、怎么运转、怎么失稳、怎么修复”。

## 核心问题

- 如果只保留一个 politics 解释模板，应该优先保留哪条链路？
- 为什么“增长问题”会在后半程转成“权利与承接问题”？
- 如何把财政土地约束纳入人口流动与治理稳定的同一框架？

## 为什么值得继续积累

- 这张集合已经能直接用于解释 politics 主轴，不依赖长篇背景铺垫。
- 它为后续新材料提供了同一校准尺：必须能映射到六段链路之一。

## 适用场景与痛点

- 需要用 3-5 分钟说明 politics 目录时。
- 需要把《筚路维艰》与《置身事内》放进同一解释框架时。
- 需要区分“国家变强”和“社会变稳”这两个常被混淆的问题时。

## 可用引用

- `国家先要被压实，才有余地被分工`
- `工业化不只问增长，也在问谁先承担代价`
- `动员力大过反馈力时，全国都可能变成实验承压面`
- `恢复不是退场，而是把市场信号、专业能力和思想空间接回治理`
- `人口流动释放之后，核心变量变成权利整合与财政承接`
- `国家强，不等于社会稳`

## 我的角度

- politics 的可复用性来自顺序，而不是信息密度。
- 只要顺序固定，新加材料就不会把框架冲散。

## 推荐顺序

1. 用 `concept-0003`、`concept-0004` 起手，回答国家如何先形成。
2. 用 `concept-0007`、`concept-0008`、`concept-0011` 说明能力如何被建出来。
3. 用 `concept-0013`、`concept-0015`、`concept-0016` 说明强动员如何走向高风险与自我毁伤。
4. 用 `concept-0017`、`concept-0018` 说明系统如何恢复弹性。
5. 用 `concept-0001`、`concept-0002`、`concept-0021` 说明成熟治理如何运转。
6. 用 `concept-0019`、`concept-0020` 与 `action-0011` 说明后半程城市化为何变成权利-财政承接问题。
7. 用 `concept-0005`、`concept-0006`、`concept-0009`、`concept-0010`、`concept-0012`、`concept-0014` 收束“国家能力不等于社会稳定”。

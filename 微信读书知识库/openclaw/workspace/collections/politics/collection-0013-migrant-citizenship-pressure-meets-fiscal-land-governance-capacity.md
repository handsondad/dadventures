# 对照轴线

`流动压力来自改革释放，承接能力受财政土地接口约束。`

- 《筚路维艰》解释压力形成：农村改革 -> 乡镇企业 -> 民工潮 -> 市民化诉求。
- 《置身事内》解释承接约束：分税制 -> 土地财政 -> 融资逻辑 -> 地方治理能力边界。

## 最小可复用比较

1. 压力侧
   - 重点看 `concept-0019`、`concept-0020`。
2. 承接侧
   - 重点看 `concept-0002`、`concept-0021`。
3. 统一诊断
   - 用 `action-0011` 走四段检查：流动规模/权利整合/财政空间/服务承接。

## 可调用结论

- 后半程城市化的核心不是继续加速流动，而是把流动转化为可承接的权利结构。
- 财政与治理接口不升级，增长红利会转化为长期治理摩擦。

# 对照轴线

`危机升级看约束，系统韧性看承接。`

- 《债务危机》提供约束轴：名义信任、外部融资、政策空间如何被压缩。
- 《沙特公司》提供承接轴：现金引擎、能力升级、治理承载如何把收益转成持续能力。

## 最小可复用比较

1. 约束侧（Debt Crises）
   - 危机为何从现金流升级到货币与外部融资。
   - 关注 `concept-0019`、`concept-0020`。

2. 承接侧（Saudi Company）
   - 资源如何被组织成能力并长期承接。
   - 关注 `concept-0015`、`concept-0018`。

3. 统一诊断
   - 用 `concept-0021 + action-0011` 做四格检查：信任/融资/现金引擎/治理承接。

## 可调用结论

- 约束强但承接弱，危机更可能持续升级。
- 约束强但承接强，危机更可能转为可管理分配。

# MEMORY.md

- 这个工作区的目标是把 Agent 固化成读书知识库与想法碎片助手，而不是通用助手。
- 原始微信读书笔记导出是素材层，结构化知识卡和主题包才是主要答案层。
- 主要事实来源顺序会根据问题类型切换：概念问题优先 `concepts/`，动作问题优先 `actions/`，场景和问题检索优先 `collections/`，书本原意问题优先 `sources/notes/`。
- `ideas/` 是想法沉淀层，不是底层事实层。
- `_templates/` 只用于写作，不用于回答。
- 新的书摘内容应先进入 `sources/books/` 和 `sources/notes/`，再拆成概念卡和动作卡，再整理主题包，最后再沉淀想法卡。
- 没有现成来源时，可以做“基于现有知识库模式整理的草案”，但不能伪造成已有书籍依据。
- 默认使用中文；优先输出定义清晰、判断明确、可直接复用、可继续延展的内容。
